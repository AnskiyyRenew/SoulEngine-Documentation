# Collisions

This library detects whether bullets and the player overlap.

---

## Core function

`collisions.FollowShape(sprite)`
Get the sprite's transformed shape data.

```lua
local shapeData = collisions.FollowShape(sprite)
```
Return value:
```
{
    x = transformed center x,
    y = transformed center y,
    w = width (absolute value),
    h = height (absolute value),
    angle = rotation angle
}
```

## Collision functions

### collisions.RectangleWithPoint(rectangle, point)
Detect collision between a rectangle and a point.
This function is used for bullet-player collision detection.

```lua
local rect = collisions.FollowShape(sprite1)
local point = collisions.FollowShape(sprite2)

local isColliding = collisions.RectangleWithPoint(rect, point)
```

All other collision usage is similar, so we won't repeat it here.

### Example

```lua
-- Collision detection between two rotated rectangles
local rect1 = {x=100, y=100, w=50, h=30, angle=30}
local rect2 = {x=120, y=110, w=40, h=25, angle=60}

if collisions.RectangleWithRectangle(rect1, rect2) then
    print("Two rectangles collided!")
end

-- Collision detection between an ellipse and a rectangle
local ellipse = {x=200, y=200, w=40, h=20, angle=45}  -- w,h are axis lengths
local rectangle = {x=210, y=190, w=30, h=15, angle=0}

if collisions.RectangleWithCircle(rectangle, ellipse) then
    print("Ellipse and rectangle collided!")
end
```
