# Beat

`Scripts/Libraries/Beat.lua` provides a simple beat event handler.

If you need precise beat synchronization — for example, creating music-driven games, or simply syncing to the rhythm / audio visualization...

Then this library is for you.

---

## Main modules and methods

### Configuration

- `SetBPM(new_bpm)`: set the BPM value (must be positive).
- `SetCycleLength(length)`: set the beat cycle length (for example, 4 beats per measure).

### State retrieval

- `GetBeat()`: returns the current beat integer part and fractional part.
- `GetBar()`: returns the current bar number and the beat position within the cycle.

All return values are 1-based.

### Event handling

- `RegisterEvent(event_type, handler)`: register an event callback (supports `beat` and `reset`).

### Beat control

- `SetBeat(beat)`: directly set the current beat (triggers reset events).
- `Reset()`: reset the beat to 0 while keeping the BPM setting.

### State update

- `Update(dt)`: update the beat state based on time delta (dt).
- `UpdateFromTime(time)`: update the beat state based on music time.

Both automatically trigger beat events and cycle detection.

### Condition checks

- `OnBeat(target_beat)`: checks whether the target beat has been reached (supports relative beat detection within a cycle).

## Examples

Two example scenes are available under `Scripts/Scenes/TestPlace`: `scene_beat.lua` and `scene_beat_from_time.lua`.

Their overall structure is essentially the same, except the former uses `Update(dt)` to update the beat, while the latter uses `UpdateFromTime(time)`.

First, we need to import the library — typically paired with an [audio](./7.md) track.

```lua
-- Importing audio here
local mus, ins = audio.PlayMusic("mus_options_winter.ogg", 1.0, true)

-- Then import the beat library here
local beat = require("Scripts.Libraries.Beat")
```

Then, we need to initialize the metronome — after all, it doesn't yet know your music's BPM, nor has any callbacks been registered.

```lua
function setupBasicBeatTracking()
    -- Set the BPM
    beat.SetBPM(140)

    -- Register the "beat" callback. It triggers on every beat, calling function(current_beat)
    -- We're implementing a simple metronome here!
    beat.RegisterEvent("beat", function(current_beat)
        local beat_sound = current_beat % 4 == 1 and "metronome_high.wav" or "metronome_low.wav"
        audio.PlaySound("Beats/" .. beat_sound, 1.0, false)
        print(string.format("Triggered on the %d beat!", current_beat))
    end)

    -- Register the "reset" callback. It triggers when the metronome is Reset().
    beat.RegisterEvent("reset", function(beat)
        print(string.format("Beat reset to: %.2f", beat))
    end)
end

-- After declaring this function, you can and should call it.
setupBasicBeatTracking()
```

But that alone won't make the metronome work — because the time tracked internally hasn't been updated at all.

We need to update the metronome in the update loop. There are two options — and this is the only difference between the two example files.

---

Option A: Pass in dt directly.

```lua
function SCENE.update(dt)
    beat.Update(dt)

end
```

If you do this, the metronome will sync with the game's update(dt) timing. This works for simple scenarios.

However, if the audio is very long — or you need strict alignment with the audio and don't want the music and metronome to drift apart — you should use:

Option B: Drive with music time.

```lua
function SCENE.update(dt)
    beat.UpdateFromTime(mus:tell())
end
```

`mus:tell()` returns the current playback position of the audio. This ensures the metronome follows the audio — even if the audio stutters or glitches.

## Other references

Here are some additional examples for reference.

Note that these code examples are for reference only; actual implementation needs to be adapted within your own framework.

```lua
-- Import the Beat manager
local beat = require("Scripts.Libraries.Beat")

-- Example 1: basic beat tracking and event triggers
function setupBasicBeatTracking()
    -- Set BPM to 120 (common pop tempo)
    Beat.SetBPM(120)

    -- Register a beat event: triggers on every whole beat
    Beat.RegisterEvent("beat", function(current_beat)
        print(string.format("Beat %d triggered!", current_beat))
    end)

    -- Register a reset event
    Beat.RegisterEvent("reset", function(beat)
        print(string.format("Beat reset to: %.2f", beat))
    end)
end

-- Example 2: rhythm-synced game logic
function gameBeatExample()
    Beat.SetBPM(140)  -- set a faster tempo
    Beat.SetCycleLength(4)  -- 4-beat measure

    -- Simulated game update loop (dt is frame delta)
    function gameUpdate(dt)
        Beat.Update(dt)  -- update beat state

        -- Detect a specific beat point (like the first beat of the measure)
        if Beat.OnBeat(0) then
            spawnEnemy()  -- spawn an enemy on the strong beat
        end

        -- Detect the third beat inside the cycle
        if Beat.OnBeat(2) then
            triggerSpecialEffect()  -- trigger an effect
        end

        -- Get beat info for UI display
        local integer_beat, fractional_beat = Beat.GetBeat()
        updateBeatUI(integer_beat, fractional_beat)
    end
end

-- Example 3: audio visualization
function audioVisualizationExample()
    Beat.SetBPM(90)
    Beat.SetCycleLength(8)  -- 8 beats per phrase

    function onAudioFrame(dt)
        Beat.Update(dt)

        local current_bar, bar_beat = Beat.GetBar()

        -- Adjust visual intensity based on bar position
        if bar_beat < 2 then
            setVisualizerIntensity(0.5)  -- weak beat phase
        else
            setVisualizerIntensity(1.0)  -- strong beat phase
        end

        -- Highlight the first beat of each bar
        if Beat.OnBeat(0) then
            triggerBarHighlight()
        end
    end
end

-- Example 4: manual beat control (debug or special scene)
function manualControlDemo()
    -- Jump directly to a specific beat
    Beat.SetBeat(16.5)  -- jump to beat 16.5

    -- Reset the entire beat system
    Beat.Reset()
end

-- Run the example
setupBasicBeatTracking()

-- Simulate time progression (called every frame)
for i = 1, 100 do
    Beat.Update(1/60)  -- assuming 60 FPS
end
```
