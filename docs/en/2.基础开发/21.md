# Masks

When attacking, some bullets are not displayed outside the battle box.<br>
They only appear inside the battle box.

Or some UI elements only appear within a specific region and never escape.

That’s the role masks play behind the scenes.

---

## Create a mask

Use `masks.New(shape, x, y, w, h, r, value)` to create a mask.

```lua
-- Create a rectangle mask at (320, 320) with size (155, 130) and rotation 0
local mask1 = masks.New("rectangle", 320, 320, 155, 130, 0)
```

### Make a mask follow a sprite

A mask does not have to remain stationary after creation. It can change size along with the battle box.<br>

**To make a mask track a sprite easily, use this function:**<br>

`mask:Follow(sprite)`<br>

This makes the mask update its position, size, and angle together with the sprite.
```lua
-- Make mask1 follow the battle box
mask1:Follow(Arena.black)
```
