# Global

Provides in-memory variables and persistent storage (filesystem) with support for Lua table serialization and deserialization. Useful for shared game data and save management.

---

## Basic global variables

- `SetVariable(name, value)`: set a memory-only variable.
- `GetVariable(name)`: get a variable value.
- `EnsureVariable(name, value)`: ensure a variable exists; if not, initialize it.

```lua
-- Set a variable
global:SetVariable("playerName", "Alice")

-- Get a variable
local name = global:GetVariable("playerName")
print(name) -- Output: Alice

-- Ensure a variable exists. If it doesn't, return 0 instead.
local score = global:EnsureVariable("score", 0)
```

## Persistent save variables

These variables are stored in the `save/` directory and remain until deleted by code or manually.

- `SetSaveVariable(name, value)`: save a variable to the filesystem.
- `GetSaveVariable(name)`: read a saved variable from the filesystem.
- `EnsureSaveVariable(name, value)`: ensure a saved variable exists.
- `DeleteSaveVariable(name)`: delete a saved variable file.

```lua
-- Save game settings
local settings = { volume = 0.8, fullscreen = true }
globals:SetSaveVariable("settings", settings)

-- Load saved settings
local loadedSettings = globals:GetSaveVariable("settings")
if loadedSettings then
    print("Volume:", loadedSettings.volume)
end

-- Delete the save entry
globals:DeleteSaveVariable("settings")
```
