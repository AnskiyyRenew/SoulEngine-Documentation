# Main file (main.lua)

As I said before, `main.lua` is the core of a game. Without it, the game cannot run. So what exactly is inside `main.lua`?
<br>

***Notice: most of the content here does not need to be modified by yourself. This section only explains the code and contains no ready-to-use examples. If you want to start developing quickly, please move on to the next topic.***

---

## Detailed explanation of main.lua

Although the code in `main.lua` looks large, it can actually be explained in chunks.<br>
First at the beginning:

```lua
if (not _RELEASED) then
    if (love.system.getOS() == "Windows") then
        local handle = io.popen("chcp 65001", "r")
        handle:close()
    end
end
```
This code opens the terminal in `UTF-8` mode so that printed text can display Chinese correctly.<br>
Try removing this part and you will see all Chinese become garbled.
<br><br>

Next comes a large number of `require` libraries.<br>
Does seeing these make you nervous? Don’t worry, this is just the underlying content the engine needs.
```lua
-- Libraries
global = require("Scripts.Libraries.GlobalVariables")   -- global variables library
maths = require("Scripts.Libraries.Utils.Mathematics")  -- mathematics library
collisions = require("Scripts.Libraries.Collisions")    -- collision library
keyboard = require("Scripts.Libraries.Keyboard")        -- input library, including keyboard, mouse, touch
masks = require("Scripts.Libraries.MaskManager")        -- mask library
audio = require("Scripts.Libraries.AudioManager")       -- audio library
layers = require("Scripts.Libraries.Utils.Layers")      -- layer library
sprites = require("Scripts.Libraries.SpritesManager")   -- sprite library
typers = require("Scripts.Libraries.TyperManager")      -- typer/text library
scenes = require("Scripts.Libraries.SceneManager")      -- scene library
tween = require("Scripts.Libraries.Tween")              -- tween animation library
windows = require("Scripts.Libraries.Utils.Windows")    -- window library
localize = require("Localization.zh_CN")                -- localization library
gui = require("Scripts.Libraries.GUIManager")           -- GUI library
luaex = require("Scripts.Libraries.Utils.LuaExtended")  -- Lua extension library
require("Localization.LOCALIZE")                        -- localization feature library
require("Scripts.Libraries.Overworld.ConfigData")       -- Overworld database
```
Although it looks like a lot, these are all used later in development. This page will explain what each library does and how to use it.<br><br>

Next comes the canvases:
```lua
-- Canvases
CANVAS = love.graphics.newCanvas(
    love.graphics.getWidth(),
    love.graphics.getHeight(),
    nil,
    {
        format = "stencil",
        readable = true
    }
)
CANVAS:setFilter("nearest", "nearest")      -- disable anti-aliasing
INTERMEDIATE_CANVAS = love.graphics.newCanvas(
    love.graphics.getWidth(),
    love.graphics.getHeight(),
    nil,
    {
        format = "stencil",
        readable = true
    }
)
INTERMEDIATE_CANVAS:setFilter("nearest", "nearest")
```
Think of it this way: **everything you see in the window, including images and text, is rendered through a canvas — a huge container.**<br>
Since we use `Shaders`, we need two canvases at the same time.<br>
**That’s why there is CANVAS and INTERMEDIATE_CANVAS.**<br><br>

Then some global variables are initialized:
```lua
-- Global variables
global:SetVariable("FPS", 60)                   -- game framerate lock
global:SetVariable("ScreenShaders", {})         -- number of screen shaders currently active
global:SetVariable("LAYER", 30)                 -- set a variable named LAYER to 30
global:SetVariable("EncounterNobody", false)    -- used by Overworld for "no encounter" battles
local reset_room = "scene_logo"                 -- room to teleport to when player presses F2

-- Initialize the camera, which can scale and rotate the overall screen view.
local Camera = require("Scripts.Libraries.Utils.Camera")
_CAMERA_ = Camera:new(0, 0, 1, 1, 0)

-- Calculate fullscreen scale while preserving black bars and centering.
screen_w, screen_h = love.graphics.getDimensions()
scale = math.min(screen_w / CANVAS:getWidth(), screen_h / CANVAS:getHeight())
draw_x = math.floor((screen_w - CANVAS:getWidth() * scale) * 0.5 + 0.5)
draw_y = math.floor((screen_h - CANVAS:getHeight() * scale) * 0.5 + 0.5)

-- Frame rate control variables.
local frameTime = 1 / global:GetVariable("FPS")
local startTime
```

After that are `Update` and `Draw`. You usually do not need to modify that code directly, because later development rarely requires editing this page.
