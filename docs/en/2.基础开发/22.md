# Tween animations

In real life, objects never move with perfect linear speed. Their velocity usually speeds up and slows down, not stay constant.<br>

The Tween library implements this behavior, making tween animations easy to use.

---

## Create a tween animation

Use `tween.CreateTween(variableSetter, type, direction, begin, final, duration, delay, destroy)` to create a tween.<br>

- `variableSetter`: a callback that receives the current value.
- `type`: the tween function.
- `direction`: one of `in`, `out`, `inout`.
- `begin`: starting value.
- `final`: target value.
- `duration`: animation duration.
- `delay` (optional): how many frames to wait before starting.
- `destroy` (optional): how many frames before the tween is removed, even if it hasn't finished.

```lua
local sprite = sprites.CreateSprite("poseur.png", 0)
tween.CreateTween(
    function (value)
        sprite.x = value
    end,
    "quad", "inout", 320, 500, 60, 10
)
```
This code moves the sprite's `x` from 320 to 500 over 60 frames, starting 10 frames later.

## Create a custom tween easing

Use `tween.CreateCustomTween(name, easingFunc)` to define a custom easing function.

```lua
-- Create a custom easing function
tween.CreateCustomTween("myEase", function(progress)
    -- Custom easing logic
    return progress * progress * (3 - 2 * progress)  -- smoothstep
end)

-- Use the custom easing
tween.CreateTween(
    function(v) someVar = v end,
    "myEase", "", 0, 100, 60
)
```

**Note: To ensure a custom tween works properly, it should satisfy `f(0)=0` and `f(1)=1`, and remain continuous in between.**
