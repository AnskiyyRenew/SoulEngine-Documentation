# Player

In SoulEngine, the player is not an independent entity. It is created inside the `Battle` system.
So most player-related changes are tied to turn-based bullet patterns.

---

## Set the player soul

Use `Player.SetSoul(number)` to set the player soul.

Currently available values are `1` and `6`, representing the red soul and the blue soul.

```lua
Player.SetSoul(1)
```

### Soul-specific methods

Currently only the blue soul has extra methods:

- `BluePlatform(x, y, layer)`: create a platform that the blue soul can stand on.
- `BlueSlam(direction, angle, hp, hurt_time)`: slam the blue soul at the given angle. `direction` controls the current control direction. If not changed, the input direction remains the same even if the player rotates 180 degrees. This consumes `hp` health and grants `hurt_time` frames of invincibility.
- `BlueSlamAuto(angle, hp, hurt_time)`: slam with automatic direction adjustment based on the angle. This consumes `hp` health and grants `hurt_time` invincibility.
- `BlueAngle(direction, angle)`: change only the blue soul angle; like `Slam`, you must manually set `direction`.
- `BlueAngleAuto(angle)`: works like `SlamAuto`.

## Set player attributes

You can modify the player's HP directly, or make the player unable to move (for example, the original game intro and `Omega Flowey` battle start).

### Player variables (attributes)

- `Player.sprite`: the player sprite, the red soul image.
- `Player.name`: the player's name.
- `Player.lv`: the player's level.
- `Player.maxhp`: the player's maximum HP.
- `Player.hp`: the player's current HP.
- `Player.kr`: the player's KR.
- `Player.soulMode`: the current soul mode (`1` for red, `6` for blue).
- `Player.canMove`: whether the player can move (default `true`, can be changed to `false` at specific times).
- `Player.speed`: the player's movement speed.
- `Player.hurting`: whether the player is currently invincible.
- `Player.hurtingTime`: how many frames of invincibility remain.
- `Player.isMoving`: whether the player is currently moving (that is, their x or y coordinate is changing).

### Player methods

Besides some manually set operations, many player behaviors can be controlled through methods.
**In addition to `SetSoul`, there are other useful functions available.**

- `Player.Hurt(damage, time, sound)`: hurt the player and grant invincibility, optionally playing a sound.
    - `damage`: amount of damage taken.
    - `time`: invincibility time in frames. If the game runs at 60 FPS, use 60 for one second.
    - `sound`: whether to play sound.
- `Player.Heal(value, sound)`: restore player HP, optionally without sound.
    - `value`: amount healed.
    - `sound`: whether to play sound.
