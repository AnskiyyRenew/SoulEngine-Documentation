# Configuration file (conf.lua)

Have you ever wondered —<br>
How is the window title set? How is the window size set? How is the error display configured? ...<br>

**This is where the answers live. The conf.lua file configures those things.**

---

## Where the configuration file is located

The configuration file, like `main.lua`, must be placed in the top-level project directory.

---

## What the configuration file contains

Let’s first look at the content before the `love.conf` function:

```lua
-- Soul Engine Configuration File
_VERSION = "2.4.2-alpha"

-- Set to true when building the game for release
_RELEASED = false

-- The game's information
_INFO = {
    TITLE = "SOUL ENGINE",
    VERSION = "0.0.0", -- THIS IS YOUR GAME'S VERSION, the "_VERSION" above refers to the engine version.
    AUTHOR = "Clavo Sophame",
    CONTACT = "NaN",
    WEBSITE = "NaN"
}

-- This is your window size. Change these values to set your desired resolution.
LOGICAL_WIDTH, LOGICAL_HEIGHT = 640, 480

-- Set to true to make the game fill the entire screen while maintaining aspect ratio
FILL_SCREEN = true

-- Enable error handler to show custom error screen
-- If you don't know which error crashed the game, set this to false.
USE_ERRHANDLER = false
```
Below is an explanation of these variables:

- `_VERSION`: the SoulEngine version number. It is described in the first chapter of the Getting Started Guide.
- `_RELEASED`: whether this game is a release build. If you are packaging the game for release, set this variable to `true` before packaging.
- `_INFO`: contains five fields. Change them to match your own game project after copying the SoulEngine template.
- `LOGICAL_WIDTH, LOGICAL_HEIGHT`: the initial window size for the game. The default is `640, 480`, the same as the original UT window size.
- `FILL_SCREEN`: controls whether the game view is centered with black bars. If set to `false`, the game view will always stay in the top-left corner regardless of window size.
- `USE_ERRHANDLER`: enable this variable to use SoulEngine's custom error page. If the game crashes and it is hard to get the error code, set this variable to `false`.


Then comes the `love.conf` function. Every setting is commented there, so read it directly.

Afterward, the region controlled by the `USE_ERRHANDLER` variable appears. If this variable is set to `true`, SoulEngine's custom error style will be used.

---

## Configuration file notes

As with other libraries and scene files, fields declared without `local` in the configuration file are treated as **global variables**.<br>

In other words, all variables listed above are global and can be modified from any scene. Adjust them carefully at the right time.
