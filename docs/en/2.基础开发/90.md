# SuperStep

You may have seen smooth bullet patterns that do not move in a straight line from one place to another. They may curve back, change color, or perform more complex actions. These are driven by SuperStep events.

**Strictly speaking, this page is a recommended method, not a requirement.**

---

## A more intuitive explanation

At its core, SuperStep means an object's `logic` callback function.

```lua
local spr = sprites.CreateSprite("bullet.png", 0)

-- Initialize a timer that belongs to this sprite
spr._time = 0

-- SuperStep event: the object updates itself using its own logic
spr.logic = function(self)

    -- Increase the timer every frame
    self._time = self._time + 1

    -- If time is within 60, move right slowly
    if (self._time <= 60) then
        self.x = self.x + 1
    end
end
```

Because it can control the sprite's properties every frame, this pattern is widely used in turn-based bullet logic.

---

## Notes

Not all scenes automatically support `logic`. You may need to write your own loop that calls `logic` for each object. Here is an example:

```lua
for i = #egtable, 1, -1 do
    local o = egtable[i]
    if (o.logic) then
        o:logic()
    end
end
```

**The code above calls each object's `logic` function if it exists.**
