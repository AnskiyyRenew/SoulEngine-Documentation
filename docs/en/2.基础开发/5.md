# Typers

If you want typewriter effects or tagged text formatting such as BBCode-like features, see this page.

> 2.5.1 update: DrawText now supports `\n` for new lines.

---

## Text creation methods

SoulEngine has two types of text: `typewriter` style and `direct draw` style.

Here are the creation methods for both types:

### typers.CreateText(sentences, position, layer, bubblesize, progressmode) -> table

This function creates a typewriter effect text object.

- `sentences`: the text to type, either a string or a table.
- `position`: position as `{x, y}`.
- `layer`: layer number.
- `bubblesize`: bubble size as `{w, h}`.
- `progressmode`: typing mode. If omitted, the default is `none`. Available modes are:
    - `manual`: manual mode. Progress advances only by manual input.
    - `auto`: automatic mode. After each sentence finishes, it waits 3 seconds and proceeds automatically. Manual input cannot interrupt it.
    - `none`: code mode. Cannot be manually controlled, only via code.

```lua
-- Typewriter text defined by a table of sentences.
local t = typers.CreateText({
    "This is the first sentence",
    "This is the second sentence"
}, {320, 240}, 1.1, {0, 0}, "manual")

-- Typewriter text defined by a single string.
local t = typers.CreateText("This is a sentence", {320, 240}, 1.1, {0, 0}, "manual")
```

### typers.DrawText(text, position, layer) -> table

This function draws text directly, skipping the typewriter effect.

- `text`: text to display.
- `position`: position to draw at.
- `layer`: layer number.

```lua
-- Draw START at (320, 240) on layer 1.
local t = typers.DrawText("START", {320, 240}, 1)
```

## DrawText color notes

When using `typers.DrawText`, changing the color does not take effect immediately. You must set the object's `color` field and then call `:Reparse()` to apply the change. For example:

```lua
local t = typers.DrawText("Hello", {320, 240}, 1)
t.color = {1, 0, 0}
t:Reparse()
```

If you want to dynamically change the entire text's opacity or color, you also need to call `:Reparse()` after modifying the corresponding fields.

## Text tags

### DrawText tags

Tagging is used to embed formatting controls into text, such as color, font, scale, and offset. Tags are written with square brackets like `[red]` or `[font=simsun.ttc,13]` and affect subsequent characters until a new tag overrides them.

Common tags:

- `[colorName]`: use a preset color name, such as `red`, `green`, `blue`, `yellow`, `white`, or `black`.
- `[font=fontname,size]`: switch font and font size, for example `[font=simsun.ttc,13]`.
- `[scale=number]`: scale characters, for example `[scale=2]` doubles the size.
- `[spaceX=number]`: set character spacing.
- `[offsetX=number]` / `[offsetY=number]`: adjust draw offset.
- `[preset=name]`: use a preset (implemented presets include `selection`, `chinese`, `chd`, etc.).

Tags are parsed by `typers.DrawText` during rendering. If you modify `rawtext` at runtime, call `:Reparse()` to regenerate the parsed text.

### CreateText tags

`typers.CreateText` supports richer tags in `[...]` format. These tags can change font, color, pauses, sound, function calls, and more while typing.

Supported tags include:

- `colorRGB:r,g,b`: set color by RGB values (0-1), e.g. `[colorRGB:1,0,0]`.
- `colorHEX:rrggbb`: set color by hex code, e.g. `[colorHEX:FF0000]`.
- `fontIndex:n`: switch to the nth font in the font list.
- `font:name`: switch to a specific font.
- `fontSize:n`: set font size; can use `index,size` to set a specific font index size.
- `alpha:n`: set opacity (0-1).
- `offset:index,x,y`: set offset for a specific font index.
- `voice:name`: switch the typing sound effect.
- `sound:name[,islooping]`: play a sound effect, optionally looping.
- `space:index,number`: set character spacing.
- `wait:n`: pause for n frames before continuing typing.
- `waitALL:n`: set both typing interval and sleep to n frames.
- `waitKEY:key`: wait until the specified key is pressed.
- `scale:n`: change scale.
- `speed:n`: adjust speed by changing the internal `sleep` value.
- `effect:name,intensity`: apply an effect such as `shake` or `rotate`.
- `function:funcName|param1,param2,...`: call a global function with parameters.
- `pattern:chinese|english`: switch Chinese/English layout mode (font index, scale, spacing).
- `RESET:what` or `RESET`: reset a specific property (`color`, `font`, `fontSize`, `alpha`, `position`) or all properties.

There are also some word-style tags that do not use a colon:

- `skip` / `instant`: skip the remaining text instantly.
- `shadow` / `noshadow`: enable or disable shadow.
- `noskip`: disable skipping.
- `voice` / `novoice`: enable or disable typing sound.
- `canskip`: allow skipping.
- `next`: move to the next sentence immediately.

Example:

```lua
local t = typers.CreateText({"[colorRGB:1,0,0]Red text[RESET] normal text"}, {320,240}, 1.1, {0,0}, "manual")
```

Tags are applied during parsing and affect subsequent characters. Some tags, like `waitKEY`, pause typing until the condition is met.

## Methods

Below are methods available on `typers.CreateText` and `typers.DrawText` instances.

### CreateText instance methods (metatable `functions`)

- `:Reset()`: reset the typer state, clear displayed characters, and restore default speed, font, color, etc.
- `:GetLettersSize() -> width, height`: return the width and height of generated letters.
- `:ShowBubble(direction, position)`: show a dialogue bubble and point its tail toward `direction` (`"left"`/`"right"`/`"up"`/`"down"`); `position` is the relative tail position.
- `:HideBubble()`: hide the current bubble by setting its alpha to 0.
- `:SetText(texts, instant)`: set the displayed sentences. `texts` can be a string or an array of strings; `instant = true` fills the current sentence immediately.
- `:Destroy()`: destroy the instance and release resources.
- `:Remove()`: alias for `Destroy()`.

The CreateText instance also exposes two callbacks:
- `OnUpdating`: called before each new character is generated.
- `OnComplete`: called when all sentences are finished.

Example:

```lua
local t = typers.CreateText({"This is a sentence"}, {320,240}, 1.1, {0,0}, "manual")
-- Show the bubble on the right at 0.2 relative position.
t:ShowBubble("right", 0.2)
-- Change the sentence and fill it immediately.
t:SetText("New text", true)
-- Destroy.
t:Destroy()
```

### DrawText instance methods (metatable `functions_instant`)

- `:GetLettersSize() -> width, height`: calculate and return the parsed text size.
- `:SetText(text)`: set `rawtext` and immediately call `:Reparse()`.
- `:MoveTo(x, y)`: move the text and reparse if needed.
- `:Destroy()`: destroy the instance and release font and parsed data.
- `:Remove()`: alias for `Destroy()`.

Example:

```lua
local d = typers.DrawText("START", {320,240}, 1)
-- Change text and apply.
d:SetText("New content")
-- Move position.
d:MoveTo(100, 200)
-- Get size.
local w, h = d:GetLettersSize()
-- Destroy.
d:Destroy()
```

Note: if you modify fields like `color` or `alpha` on a DrawText instance, call `:Reparse()` or use `:SetText()` to apply the change.
