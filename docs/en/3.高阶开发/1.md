# Shaders (Shader)

Found a great shader on Shadertoy, but copying it directly into love2d requires a lot of changes and still may not produce the same result.<br>

**The ShaderToy.lua library can solve this problem perfectly.**

---

## Basic Usage

### Initialize the library

```lua
local shadertoy = require("shadertoy")

-- Create a single shader

local shaderCode = [[
void mainImage(out vec4 fragColor, in vec2 fragCoord)
{
    vec2 uv = fragCoord / iResolution.xy;
    fragColor = vec4(uv, 0.5, 1.0);
}
]]

local myShader = shadertoy.convert(shaderCode)
```

### Using the shader

If you want to apply it directly to a sprite:
```lua
local shader = myShader.shader
sprite:SetShaders({shader})
```

If you want to use it inside a drawing function (`love.draw/SCENE.draw/wave.draw`):
```lua
function love.draw()
    myShader:apply()
        love.graphics.rectangle("fill", 0, 0, love.graphics.getWidth(), love.graphics.getHeight())
    myShader:clear()
end

function love.update(dt)
    myShader:update(dt)
end
```

## Multi-Pass Rendering Projects

Now imagine a shader that requires rendering `Buffer A/B/C`, and each buffer is usually written as separate code. How do you convert that?

**The answer is to create a project, store all of the code there, and then render it sequentially according to the logic.**

### Create a multi-pass project

```lua
-- Create a new project
local project = shadertoy.newProject()

-- Add render passes
project:addPass("bufferA", [[
void mainImage(out vec4 fragColor, in vec2 fragCoord)
{
    // First pass shader code
    vec2 uv = fragCoord / iResolution.xy;
    fragColor = vec4(sin(uv.x * 10.0 + iTime), cos(uv.y * 10.0), 0.5, 1.0);
}
]])

project:addPass("bufferB", [[
void mainImage(out vec4 fragColor, in vec2 fragCoord)
{
    // Second pass shader code, which can use the result from the previous pass
    vec4 prev = texture(iChannel0, fragCoord / iResolution.xy);
    fragColor = vec4(prev.rg, 0.5, 1.0);
}

]])

project:addPass("final", [[
void mainImage(out vec4 fragColor, in vec2 fragCoord)
{
    // Final output pass
    vec4 bufferA = texture(iChannel0, fragCoord / iResolution.xy);
    vec4 bufferB = texture(iChannel1, fragCoord / iResolution.xy);
    fragColor = mix(bufferA, bufferB, 0.5);
}
]])
```

### Update and draw the project

After creating the project, you need to render it on the screen:

```lua
function love.update(dt)
    project:update(dt)
end

function love.draw()
    project:draw()
end
```

## Texture Channel Setup

In Shadertoy, some shaders place an image in `iChannel0` or another channel, and it may be a normal image or a noise texture.<br>

For noise textures, the wrong assumption is that these noise images are always the same. In reality, each noise texture is **randomly generated**.

### Set a custom texture

```lua
-- Set a noise texture generated randomly at 512x512
myShader:setChannel(0, myShader:generateNoiseTexture(512))

-- Set an image texture
local image = love.graphics.newImage("texture.png")
myShader:setChannel(1, image)
```

### Audio texture support

```lua
-- Set an audio channel (FFT data)
myShader:setAudioChannel(2, "music.mp3")
```

## Available Uniform Variables

| Variable | Type | Description |
|-------|------|------|
| `iTime` | number | Elapsed time (seconds) |
| `iTimeDelta` | number | Frame delta time |
| `iFrame` | int | Frame counter |
| `iResolution` | vec3 | Resolution (width, height, 1) |
| `iMouse` | vec4 | Mouse position and click state |
| `iChannel0-3` | Image | Texture channels |
| `iChannelResolution[4]` | vec3 | Texture resolutions |

## Code Debugging

### View the converted code

```lua
-- Print the final converted code
myShader:printCode()

-- Print the original code
myShader:printCode("original")

-- Print extern declarations
myShader:printCode("extern")

-- Save code to a file
myShader:printCode("final", "converted_shader.glsl")
```

## Complete Example

```lua
function love.load()
    shadertoy = require("shadertoy")
    -- Create a simple shader
    local code = [[
    void mainImage(out vec4 fragColor, in vec2 fragCoord)
    {
        vec2 uv = fragCoord / iResolution.xy;
        float r = 0.5 + 0.5 * sin(uv.x * 10.0 + iTime);
        float g = 0.5 + 0.5 * cos(uv.y * 10.0 + iTime);
        float b = 0.5 + 0.5 * sin((uv.x + uv.y) * 5.0 + iTime * 2.0);
        fragColor = vec4(r, g, b, 1.0);
    }
    ]]

    myShader = shadertoy.convert(code)
end

function love.update(dt)
    myShader:update(dt)
end

function love.draw()
    myShader:apply()
        love.graphics.rectangle("fill", 0, 0, 800, 600)
    myShader:clear()
end
```

## Notes

1. **Syntax conversion**: the library automatically converts ShaderToy syntax to LÖVE-compatible format.
2. **Texture channels**: `iChannel0-3` correspond to LÖVE texture units.
3. **Audio processing**: audio channels generate FFT and waveform textures in real time.
4. **Performance optimization**: multi-pass rendering uses ping-pong buffer techniques.

This library makes using ShaderToy shaders in LÖVE simple and direct, supporting most ShaderToy features and syntax.<br>

**Reminder: this library cannot guarantee 100% success for all shaders. Some shaders are hacky, designed to exploit floating point precision to create amazing effects, and this library alone cannot perfectly reproduce them.**
