# Exporting Maps

---

After the previous topics, you now have enough knowledge to export a usable map.

## Export Process

Press `Ctrl + Shift + E`, or click `File -> Export As`, to open the export dialog.<br>
Choose the `.lua` format, give the file a name, and save it alongside your other `.lua` files. (You can also create a dedicated folder for organization; that is not shown here.)<br>
![](../img/overworld/5-1.png)<br>

At this point, the map has been successfully exported to the `Maps/` folder. If you are ready to use it, move on to the next topic.

---

## Updating a Map

If the exported map is not quite right, do not worry. This is normal.<br>
Make the changes you want, then repeat the export process described above.
