# Lua Errors

During development, the most common issues you'll encounter are Lua runtime errors (since you're writing Lua code). To quickly find an error on this page, press `Ctrl + F` (or use your browser/mobile search) and enter a few keywords to locate the message and likely cause.

---

## Common Errors

These errors are usually caused by simple mistakes or oversight.

- `attempt to call a non-function value`<br>
	Attempting to call a value that is not a function, e.g. `local x = 123; x()`.

- `attempt to index a nil value`<br>
	Attempting to index a `nil` value, e.g. `local t = nil; print(t.key)`.

- `attempt to perform arithmetic on a string value`<br>
	Trying to do arithmetic on a string, e.g. `local s = "hello"; print(s + 5)`.

- `unexpected symbol near '...'`<br>
	Syntax error: an unexpected token in the code (usually missing parentheses or a typo).

- `'end' expected (to close 'function' at line ...)`<br>
	A block is missing its closing `end` (common in `function`, `if`, `for`, etc.).

- `bad argument #1 to '...' (expected ..., got ...)`<br>
	A function received an argument of the wrong type, e.g. `string.len()` called with a non-string.

- `cannot use '...' outside a vararg function`<br>
	The vararg `...` syntax was used outside of a vararg function.

- `'then' expected near '...'`<br>
	An `if` statement is missing the `then` keyword, e.g. `if x > 5 print(x)`.

- `attempt to compare number with string`<br>
	Comparing a number with a string, e.g. `if 5 == "5" then`.

- `attempt to concatenate a nil value`<br>
	Concatenating `nil`, e.g. `local x = nil; print("value: " .. x)`.

- `syntax error near '...'`<br>
	General syntax errors caused by typos, missing symbols, or malformed structures.

- `cannot call method '...': a nil value`<br>
	Attempting to call a method that doesn't exist on an object, e.g. `local obj = {}; obj:undefinedMethod()`.

## Threshold / Limit Errors

Note: LOVE2D's Lua environment is generally permissive, so these errors are rare. However, if you encounter any of them, the usual fix is to consolidate related variables into tables (so you use fewer top-level variables).

Example:
```lua
-- Ten separate variables
local time1, time2, time3, ...

-- Better: a single table holding the values
local time = {t1 = 0, t2 = 0, t3 = 0, ...}
```

Avoid having too many variables in the global scope, a single file, or within a function. Common limit/threshold errors include:

- `too many upvalues in function`<br>
	The function captures more external local variables (upvalues) than Lua allows.

- `too many local variables in function`<br>
	A function defines more local variables than the implementation limit.

- `too many constants in function`<br>
	The number of constants used in a function exceeds Lua's internal constant table limit.

- `control structure too long`<br>
	Extremely long `if...elseif` chains or excessively large switch/case-like constructs.

- `function or expression too complex`<br>
	Code nesting or expressions are too complex.

- `too many syntax levels`<br>
	Nesting depth (loops/conditionals) exceeds allowed levels.

- `table overflow`<br>
	Initializing a table with too many elements.

- `string length overflow`<br>
	A string literal exceeds Lua's maximum allowed length.

- `parser stack overflow`<br>
	The parser's internal stack overflows while parsing your code.

- `too many vararg functions`<br>
	An excessive number of vararg functions in the script.

- `too many captures in pattern`<br>
	A pattern (for string matching) contains more capture groups than allowed.
