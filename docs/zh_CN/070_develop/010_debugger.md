---
title: 对象调试器
---

`Debugger` 是一个 **游戏内对象调试器** ，可在游戏运行时对屏幕上的 sprite 点选、拖动、改属性，并把调好的参数导出成代码。适用于摆放位置、调整缩放与颜色、编辑四点形变，免去反复改代码并重启的过程。

库路径： `Scripts/Libraries/Engine/Debugger.lua`

!!! warning "仅开发版可用"
    这是一个开发工具，只在 `_RELEASED` 为 `false` 时加载（见 `conf.lua` ，由 `main.lua` 负责导入）。打包发布版里不会被加载。

---

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl` + `D` | 开关调试模式（进入 / 退出交互状态） |
| `F9` | 切换屏幕上信息文字的透明度（显示 / 隐藏） |

退出调试模式时，属性面板、右键菜单、正在拖动的四点手柄都会自动收起。

!!! tip "`F9` 的作用"
    `F9` 用于隐藏铺满屏幕的对象属性文字，便于在没有覆盖层的画面中查看效果，需要查看数值时再按一次显示。

---

## 选中与拖动

进入调试模式后：

- **左键点击**一个对象即可选中它，选中的对象会画出红色边框。
- 选中后 **按住左键拖动** 即可移动对象位置（拖动有一定阈值，轻微点击不会误移动）。
- 点击空白处会取消选中。

选中对象后，对象的所有字段会**逐项打印在屏幕左上角**，便于实时查看各项数值。

---

## 右键菜单

选中对象后 **右键** 会弹出上下文菜单。菜单靠近屏幕边缘时会自动翻转 / 收拢，保证始终完整显示在屏幕内。

| 菜单项 | 作用 |
| --- | --- |
| `Clone` | 以相同路径与图层再创建一个对象 |
| `Export` | 把当前对象导出成代码（见下文） |
| `Delete` | 销毁该对象 |
| `flip X` / `flip Y` | 水平 / 垂直翻转（取反对应方向的缩放） |
| `Rotate 90°` / `Rotate -90°` | 旋转 ±90 度 |
| `Properties` | 显示 / 隐藏右侧属性面板 |
| `Toggle Four-Point` | 开关四点形变模式 |
| `Reset Corners` | 把四点形变的四个角重置为对象原始矩形 |

---

## 属性面板

通过右键菜单的 `Properties` 打开，位于屏幕右侧，可以 **直接编辑** 以下字段：

`X` 、`Y` 、`ScaleX` 、`ScaleY` 、`Rot`（旋转）、`Alpha`（透明度）。

编辑方式：**点击某个字段**开始编辑，直接输入数字、小数点与负号，按 `Backspace` 删除，按 `Enter` 应用，按 `Esc` 取消。

如果对象带有 `color` 字段，面板下方还会出现 **颜色色板** ，点击色块即可实时改变对象颜色，当前颜色对应的色块会有高亮描边。

---

## 四点形变

当对象支持四点形变（带 `_four_point` 字段）时，可以开启它并拖拽四个角来任意拉伸、透视。

四个手柄各有颜色，便于区分：

| 手柄 | 位置 | 颜色 |
| --- | --- | --- |
| `TL` | 左上 | 红 |
| `TR` | 右上 | 绿 |
| `BL` | 左下 | 蓝 |
| `BR` | 右下 | 黄 |

- 点击并拖动某个手柄即可移动该角。
- 四点形变开启时拖动对象本体，四个角会作为整体一起移动。
- 属性面板里的 `Reset Corners` 可以把四个角复位成对象的原始矩形。

---

## 导出对象

右键菜单的 `Export` 会把当前对象的完整状态写成一段可运行的代码，输出到 `Debug/exported_object.lua` ，同时打印到终端。生成的形式大致如下：

```lua
-- Exported by Debugger
local spr = Sprites.CreateSprite("poseur.png", 0)
spr:MoveTo(320, 240)
spr:Scale(1, 1)
spr.rotation = 0
spr.alpha = 1
spr.color = {1, 1, 1}
spr.visible = true
spr:SetFourPointMode(true)
spr:SetFourPoint(
    260, 200,  -- top-left
    380, 200,  -- top-right
    260, 280,  -- bottom-left
    380, 280   -- bottom-right
)
```

将这段代码加入场景代码，可以复现调好后的对象。

---

## 让某个 sprite 被忽略

有些 sprite 并不希望被调试器选中或拖动 —— 例如铺满全屏的覆盖层、装饰性的背景图层。给它们设置一个标记即可：

```lua
spr.debugger_ignored = true
```

设置后，这个 sprite 会被调试器 **完全跳过** ，无法被选中、拖动、查看或导出。
