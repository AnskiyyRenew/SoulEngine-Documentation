---
title: 引擎热键
---

引擎内置了一组操作与调试热键。**多数只在开发版（ `_RELEASED = false` ）生效**，打包后自动失效。

| 热键 | 作用 | 生效范围 |
|---|---|---|
| `F2` | 重新加载本地化文本、重跑两份 `conf_pure` 配置，并切到 `F2Room` | 所有版本 |
| `F4` | 切换全屏 / 窗口 | 所有版本 |
| `F5` | **热重载**：清掉已缓存的引擎模块与 Game 区内容、重进当前场景、重新应用 Hack | 仅开发版 |
| `F6` | 向控制台打印一份调试信息（FPS、分辨率、缩放、当前场景、输入设备、贴图数、图层数、Hack 报告） | 仅开发版 |
| `F7` | 开关战斗碰撞箱（ `Battle.ToggleHitboxes()` ，战斗场景内） | 仅开发版 |
| `F8` | 开关 **变量调试器**（DevTool） | 仅开发版 |
| `F9` | 开关 **对象调试器**（Debugger）的信息文字显隐 | 仅开发版 |

!!! note "关于 F3"
    引擎**没有** `F3` ，也没有 FPS 叠加层。要看帧率，用 `F6` 打印出来的 `FPS` 字段，或按 `F8` 打开变量调试器读实时值。

---

## 各热键细节

### F2 — 重载配置与本地化
重新读取语言文件，并重新执行引擎与 Game 两份 `conf_pure.lua` ，然后跳到 `F2Room` 指定的场景。改完文案或配置想立刻看效果时用它。

### F4 — 全屏切换
在窗口与全屏之间切换，同时重算画布缩放，边框会跟着一起缩放。

### F5 — 热重载
比 `F2` 更彻底：清掉 `Scripts.Libraries` 与 Game 区的模块缓存，重进当前场景，再重新加载 `Game/Hacks/` 。**改完代码不用重启游戏**。

### F6 — 调试信息
在控制台打印一组当前状态：帧率、窗口分辨率、画布缩放、当前场景名、虚拟键盘与手柄数量、贴图数、图层对象数，以及 Hack 的注册情况。适合快速确认环境。

### F7 — 战斗碰撞箱
只在战斗场景里有意义，用来可视化完美像素判定框。相关内容见 [碰撞](../050_intermediate/030_collision.md) 与 [战斗场景与回调](../030_battle_system/070_scene.md) 。

### F8 / F9 — 两个调试器
`F8` 打开 [变量调试器](./020_devtool.md) ，`F9` 控制 [对象调试器](./010_debugger.md) 的信息文字显隐。两者的分工见各自页面。

---

## 自定义热键

热键写在 `main.lua` 的 `love.keypressed` 里：

- 全局热键（ `F2` / `F4` / `F5` / `F6` / `F8` ）直接判断 `key` 。
- 战斗内的 `F7` 由 `Battle` 每帧轮询 `Keyboard.GetState("f7")` 。

需要新增热键时，可参照对应的那一段并修改键名。
