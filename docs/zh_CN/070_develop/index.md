---
title: 辅助开发
---

---

引擎提供一组 **开发期专用的调试与辅助工具**，用于在运行时查看和修改游戏状态、可视化生成资源。
这些工具多数只在开发版生效，打包发布时会被自动排除，不会进入正式游戏。

---

## 本专题页面

| 页面 | 内容 |
|---|---|
| [场景辅助工具](./000_toolscenes.md) | 引擎内置的工具场景；贝塞尔缓动编辑器（可视化调整缓动曲线并导出代码） |
| [对象调试器](./010_debugger.md) | 游戏内点选 / 拖动 sprite、改属性、四点形变、导出对象代码 |
| [变量调试器](./020_devtool.md) | `F8` 变量树 + 控制台，实时查看与修改引擎内存中的任意字段 |
| [引擎热键](./030_hotkeys.md) | `F2` ~ `F9` 热键总表：重载、全屏、热重载、调试信息、碰撞箱、两个调试器 |
| [资源预加载](./040_preload.md) | `SE.Preload(...)` / `SE.PreloadAll()` 把 Game 区资源提前解码进缓存，避免首次引用卡顿 |
| [密钥原生库](./050_secrets.md) | 把 GameJolt 私钥之类的秘密编译进 `.dll` / `.so` 再经 FFI 取回，别留在明文里 |
| [内置资源一览](./060_bundled_assets.md) | 引擎自带 `Resources/` 里哪些资源正在被用：字体、音效、音乐、贴图、原生库的使用范围 |
