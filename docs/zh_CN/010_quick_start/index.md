title: 快速上手
---

本专题回答一个问题： `SoulEngine` 与 `LOVE2D` 安装完成之后，接下来做什么。

专题分成两段：**通用底座**四页是后面所有路线都要用到的部分，读完后能让画面跑起来；**两条路线**各自独立，选一条走完即可得到一个可运行的结果，不需要两条都做。

---

## 按想做的东西选入口

| 已经想好做什么 | 入口 |
|---|---|
| 一场能打的回合制战斗 | [第一场战斗](./040_first_battle.md) |
| 一张能走动的地图 | [第一张地图](./050_first_map.md) |
| 界面、过场演出、小游戏 | 读下方的通用底座，读完直接写自己的场景 |
| 还没决定 | 读下方的通用底座，读完再回到这里选 |

!!! note "通用底座不能跳过"
    两条路线都要先知道场景怎么建、贴图怎么放。`conf.lua` 与 `Game/conf_pure.lua` 的区别、Game 区覆盖规则也属于这一层。

## 引擎能做什么

引擎按模块划分职责，下表按"想做出的东西"给出对应的模块与查阅入口：

| 想做出的东西 | 由哪部分负责 | 查阅 |
|---|---|---|
| 回合制战斗、弹幕、敌人回合 | 战斗系统 | [战斗系统](../030_battle_system/index.md) |
| 在地图上走动、对话、存档点、箱子、遇敌 | Overworld 主世界 | [Overworld 主世界系统](../040_overworld/index.md) |
| 商店买卖、拒收台词、交谈话题 | Overworld → 商店 | [商店](../040_overworld/060_shop.md) |
| 菜单、状态页、背包 | Overworld → 菜单 | [菜单 · 存档 · 箱子](../040_overworld/040_menu.md) |
| 自定义界面、过场演出、小游戏 | 场景 + 贴图 + 打字机 + GUI | [基础开发](../020_basic/index.md) |
| 背景音乐与音效 | Audio | [基础开发 → 音频](../020_basic/050_audio.md) |
| 多语言切换 | Localize | [本地化](../080_l10n/index.md) |
| 奖杯、分数榜、云端存档 | GameJolt | [网络开发 → GameJolt](../090_network/000_gamejolt.md) |
| 打包成 exe / APK / 网页 | Packager | [导出与发布](../100_export/index.md) |

!!! tip "不属于引擎范围的部分"
    地图需要用 Tiled 编辑，图块与角色素材需要自行绘制或获取。引擎负责读取与运行这些内容，不提供制作工具。

## 两条路线

### 路线 A：一场能打的战斗

- **产出**：敌人出现在屏幕上，可完成一次攻击结算与一个敌人回合。
- **需要改动的文件**：遭遇文件、战斗场景、初始场景配置，共三处。
- **入口**：[第一场战斗](./040_first_battle.md)

### 路线 B：一张能走的地图

- **产出**：角色在地图上走动，走到标记处能触发对话。
- **需要改动的文件**：主世界场景、初始场景配置，共两处。地图可直接使用引擎自带的那张。
- **入口**：[第一张地图](./050_first_map.md)
- 自建地图需要 Tiled，见 [Overworld → 地图与对象层](../040_overworld/010_map.md) 。
