## 变量（Variable）

变量是开发过程中使用最多的概念。<br>
<u>绝大多数以 `.lua` 为后缀的文件内部都包含变量</u>。

!!! example "变量举例"
    ```lua
    a = 10          -- 单个字母
    abb = ""        -- 多个字母
    _count = 0      -- 下划线开头
    playerHP = 20   -- 驼峰命名
    ```

以上这些例子都是 `变量` 。

### 命名规范（必须遵守）

1. 变量不允许用关键词命名（如 `if` ， `end` 等）
2. 变量不允许用数字开头命名（如 `1var` 等）
3. 引擎里**统一用 ASCII**（英文字母、数字、下划线）命名

### 中文标识符

中文可以作为变量名，但不建议使用。

SoulEngine 运行在 **LuaJIT** 上（LÖVE 12 自带），而 LuaJIT 的词法分析器将 `0x80` 以上的字节也视为合法标识符字符，因此下面这段在游戏里**能够正常运行**：

```lua
你好 = ""
你好 = "hello"
print(你好)          -- hello

function 打招呼() return "hi" end
print(打招呼())      -- hi

local t = {名字 = "Chara"}
print(t.名字)        -- Chara
```

!!! warning "换用标准 Lua 解释器会报错"
    **标准 Lua 5.1（PUC）会直接拒绝**上面那些写法：

    ```
    lua.exe: t.lua:1: unexpected symbol near 'ä'
    ```

    而引擎仓库里的 `verify_*.lua` 校验脚本、部分构建/导出流程用的就是标准 Lua。
    同一份代码在两套解释器下运行，中文标识符那部分会**在另一条流程中出现语法错误**，且报错位置指向的是字节而非所写的字符。

!!! danger "统一使用 ASCII 命名"
    中文并非不能用，而是**只能放在字符串里**，以及 Tiled 图层名、注释这类供阅读与其他工具读取的位置：

    ```lua
    local greeting = "你好"      -- 字符串中的中文不受限制
    local name = "Chara"          -- 变量名使用 ASCII
    ```

    引擎内部所有变量、函数、表字段一律使用 ASCII。

### 常见类型

1. 数字： `1`, `2`, `3`
2. 字符串（也可称作文本）：`"hello"`, `"我是一个完整的句子。"`, `"滚木"`
3. 表，可同时作为数组或字典使用：`{1, 2, 3, 4}`
4. 布尔值，表示开关状态：`true`, `false`
5. 函数，与数学函数不同，通过在名称后加括号调用：`cool()`

## 关键词（Keyword）

部分标识符在语言层面具有特殊含义，编辑器会将其高亮显示为关键词。

以下为关键词与非关键词的对比：

!!! example "关键词与非关键词"
    ```lua
    if then while for do end elseif else in
    ```

    ```lua
    IF aaa time var1 incredible
    ```

关键词的高亮由编辑器识别产生，并非文档额外标记。<br>
下面给出混合版本：

!!! example "关键词高亮"
    ```lua
    if time == a then
    end
    ```

命名时应避开上述关键词。

### 常用组合搭配

以下只列出最常用的几种结构：

1.条件判断：若某个值达成条件，执行某操作。
!!! example "if语句"
    ```lua
    if time == 60 then
        a = a + 1
    end
    ```

上面语句执行：当 `time` `等于` `60` 时，执行由 `if - end` 包裹的内容（此处 `a` 增加 1）。

2.if链：按顺序匹配每个条件，确定最终进入的分支：
!!! example "if链"
    ```lua
    if     time == 60 then
                            分支一
    elseif time == 90 then
                            分支二
    elseif time == 95 then
                            分支三
    else
                            最终分支
    end
    ```

上面语句执行：当 `time` 等于 `60`、`90`、`95` 时，分别进入分支一、二、三。<br>
<u>若都不符合，则进入由 `else` 管理的最终分支。</u>

3.循环执行：用一个计数变量重复执行某操作：
!!! example "正常for循环"
    ```lua
    for i = 1, 10, 1
    do
        a = a + 1
    end
    ```

上面语句执行：新建变量 `i` ，从 `1` 开始，每次增加 `1` 直到 `10` 。<br>
<u>在此期间每递增一次都会执行一次 `for - end` 包裹的内容。</u>

该循环共执行十次。

while 循环：

!!! example "while循环"
    ```lua
    while i < 10
    do
        i = i + 1
    end
    ```

上面语句执行：当 `i` 小于 `10` 时，重复执行 `i = i + 1` ，直到 `i` 不再满足条件为止。

## 短路选择

### or 的基本语义

如果 `a` 存在或者为真，则选择 `a` ；反之选择 `b` 。<br>
该写法可用于设置默认值。

格式如下：
```
var = a or b
```

!!! example "示例"
    若调用 `test` 时未传入参数，则使用 `or` 之后的内容，此例中为 `default output.` 。
    ```lua
    local function test(b)
        print(b or "default output.")
    end
    test()
    ```

### and or 条件判断

若条件 `a` 为真，则使用 `b` ，否则使用 `c` 。<br>
该写法可在一行内完成二元或多元选择。

格式如下：
```
var = a and b or c
```

该写法需要正确处理逻辑关系与括号。

常见于划定战斗框大小最小为 `16` 的情况：
!!! example "示例"
    如果 `width` 大于 `16` ，则使用 `width` ，否则使用 `16` 。

    ```lua
    local _width = (width > 16) and width or 16
    ```

!!! example "嵌套操作"
    每一层条件依次判断， `cfg` 、 `cfg.db` 、 `cfg.db.host` 三者中只要有一个不成立，就输出 `localhost` 。

    ```lua
    local config = {
        db = { host = "127.0.0.1" }
    }

    local function getHost(cfg)
        return (cfg and cfg.db and cfg.db.host) or "localhost"
    end

    print(getHost(config))                        -- 127.0.0.1
    print(getHost({ db = {} }))                   -- localhost
    print(getHost(nil))                           -- localhost
    ```
