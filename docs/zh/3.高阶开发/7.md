# 窗口管理（Windows）

**观前须知：本页面暂不支持Linux和macOS，甚至以后也很可能无法支持。**

---

## 获取窗口句柄

使用 `window.getHandle()` 来获取窗口句柄。

```lua
local hwnd = window.getHandle()
```

---

## 处理窗口消息

使用 `window.processMessages()` 函数来处理系统窗口消息队列，需要在主循环中定期调用。

```lua
function love.update(dt)
    -- 处理 Windows 消息，防止窗口无响应
    if window.isWindows() then
        window.processMessages()
    end
end
```

---

## 窗口透明

使用 `window.setTransparency(hwnd, alpha)` 来设置一个窗口的透明度。

```lua
function love.keypressed(key)
    if key == "t" then
        local hwnd = window.getHandle()
        if hwnd then
            -- 设置窗口半透明（128/255）
            window.setTransparency(hwnd, 128)
        end
    elseif key == "o" then
        local hwnd = window.getHandle()
        if hwnd then
            -- 恢复不透明
            window.setTransparency(hwnd, 255)
        end
    end
end
```

---

## 窗口背景透明

使用 `window.setBackgroundTransparent(hwnd, colorKey, alpha)` 设置背景透明。

```lua
window.setBackgroundTransparent(hwnd, 0x000000, 0) -- 所有黑色部分透明
```

**注：此函数可以制作人物跑出窗口的效果**

## 截图

使用 `window.saveScreenshot(x, y, w, h, path, throughWindow)` 来进行指定区域截图。

```lua
function love.keypressed(key)
    if key == "p" then
        -- 截取整个窗口
        local success, message = window.saveScreenshot(0, 0, 800, 600, "screenshot.bmp", true)
        
        if success then
            print("截图保存成功")
        else
            print("截图失败:", message)
        end
        
        -- 或者截取屏幕特定区域（不通过窗口）
        window.saveScreenshot(100, 100, 400, 300, "area.bmp", false)
    end
end
```

## 显示系统对话框

使用 `window.showDialog(message, buttons, title)` 来创建一个消息对话框。

```lua
function love.mousepressed(x, y, button)
    if button == 1 then
        local result = window.showDialog(
            "确定要退出游戏吗？",
            {"是", "否", "取消"},
            "退出确认"
        )
        
        if result == 1 then -- 点击"是"
            love.event.quit()
        elseif result == 2 then -- 点击"否"
            print("继续游戏")
        else -- 点击"取消"或其他
            print("操作取消")
        end
    end
end
```
