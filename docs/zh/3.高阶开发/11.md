# 🟡Lua拓展库（LuaExtended）

也许你遇到过想要查看表内信息，却发现 `print` 函数只能返回给你一个你无法看懂的数字，最后还是无法获得有效信息的情况。

此库涵盖了对表的很多操作，使得你可以直接、高效的查看表内变量。

---

## 方法概览

### 移除表内某个变量

`rmVarTable(t, value, func)`

- `t`：目标表。
- `value`：要移除的变量。
- `func`：移除同时调用此函数。

示例：
```lua
local fruits = {"apple", "banana", "apple", "cherry", "apple"}
print("原始表：", table.concat(fruits, ", "))

-- 移除所有 "apple"，并传入一个回调函数（每次移除后自动调用）
luaextended.rmVarTable(fruits, "apple", function()
    print("已移除一个 apple")
end)

print("移除后：", table.concat(fruits, ", "))  -- banana, cherry
```

### 打印整个表

`printTable(t, indent)`

- `t`：目标表。
- `indent`：起始缩进。（默认为0）

示例：
```lua
local person = {
    name = "Alice",
    age = 30,
    address = {
        city = "Wonderland",
        zip = 12345
    },
    hobbies = {"reading", "chess"}
}
-- 制造一个循环引用
person.self = person

luaextended.printTable(person)
```

输出：
```
table (rows=4) {
    name = Alice
    age = 30
    address = 
    table (rows=2) {
        city = Wonderland
        zip = 12345
    }
    hobbies = 
    table (rows=2) {
        1 = reading
        2 = chess
    }
    self = <recursive reference>
}
```

### 查找表中是否存在元素

`findTableValue(t, value)`

- `t`：目标表。
- `value`：要查询的值。

示例：
```lua
local luaextended = require("luaextended")

local config = {
    level = 5,
    settings = {
        volume = 0.8,
        difficulty = "hard"
    },
    players = {"Alice", "Bob"}
}

print(luaextended.findTableValue(config, "hard"))   --> true
print(luaextended.findTableValue(config, "easy"))   --> false
print(luaextended.findTableValue(config, 0.8))      --> true
print(luaextended.findTableValue(config, "Alice"))  --> true
```

### 合并两个表

`patchTable(t, patch)`

- `t`：目标表。
- `patch`：要打的补丁。

示例：
```lua
local luaextended = require("luaextended")

local default = {
    name = "Default",
    version = 1.0,
    features = {
        sound = true,
        graphics = "low"
    }
}

local update = {
    version = 1.1,
    features = {
        graphics = "high"
    },
    newField = "added"
}

luaextended.patchTable(default, update)

-- 打印修改后的 default 表
luaextended.printTable(default)
```

输出：
```
table (rows=3) {
    name = Default
    version = 1.1
    features = 
    table (rows=2) {
        sound = true
        graphics = high
    }
    newField = added
}
```
