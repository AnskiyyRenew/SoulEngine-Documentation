# 安全JSON检测（SafeJson）

本库主要用于防范 `.json` 文件中的恶意代码。

---

## 安全解析json

使用 `safejson.parse(str)` 来解析一个json字符串。<br>
注：本库不会读取文件，只会读取文件里的字符串。

```lua
-- 基本解析
local json_str = '{"name": "Alice", "age": 25, "hobbies": ["reading", "swimming"]}'
local data, err, err_type = safejson.parse(json_str)

if err then
    print("解析失败:", err, "错误类型:", err_type)
else
    print("姓名:", data.name)        -- Alice
    print("年龄:", data.age)         -- 25
    print("爱好1:", data.hobbies[1]) -- reading
end
```

## JSON编码（与dkjson库相同）

```lua
local user_data = {
    name = "Bob",
    age = 30,
    preferences = {
        theme = "dark",
        language = "zh-CN"
    }
}

local json_output = safejson.encode(user_data)
print(json_output)
-- 输出: {"name":"Bob","age":30,"preferences":{"theme":"dark","language":"zh-CN"}}
```

## 高级配置选项

```lua
local options = {
    -- 危险关键词黑名单（可扩展）
    badwords = {
        ["__index"] = true,
        ["coroutine"] = true,
        -- 可添加自定义危险词
        ["malicious"] = true,
    },
    
    -- 资源限制
    max_depth = 50,           -- 最大嵌套深度
    max_items = 5000,        -- 最大项目数
    max_string_length = 50000, -- 最大字符串长度
    
    -- 功能开关
    enable_precheck = true    -- 启用预检查
}

local json_str = '{"data": "some content"}'
local data, err = safejson.parse(json_str, options)
```
