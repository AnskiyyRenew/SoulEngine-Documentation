# 计时器（TimeManager）

实现了一个基于协程的计时器管理系统，主要用于创建和管理可等待的代码块。

---

## 创建代码块

使用 `timer.CreateBlock(func, name, group)` 来创建并启动一个可等待的代码块。

```lua
-- 创建可等待的代码块
local myTimer = timer.CreateBlock(function()
    print("开始执行")

    wait(2)  -- 等待2秒
    print("2秒后执行")

    wait.frame(60)  -- 等待1秒（60帧）
    print("1秒后执行")
end, "示例定时器", "UI组")
```

## 三种等待方式

### 按秒等待
```lua
timer.CreateBlock(function()
    wait(3.5)  -- 等待3.5秒
    print("3.5秒后执行")
end)
```

### 按帧等待
```lua
timer.CreateBlock(function()
    wait.frame(30)  -- 等待30帧（假设60FPS，即0.5秒）
    print("半秒后执行")
end)
```

### 按条件等待
```lua
local canProceed = false
timer.CreateBlock(function()
    wait.ntl(function() return canProceed end)
    print("条件满足，继续执行")
end)
```

## 分组管理

```lua
-- 创建多个同组定时器
timer.CreateBlock(function() wait(1) print("定时器1") end, "timer1", "战斗组")
timer.CreateBlock(function() wait(2) print("定时器2") end, "timer2", "战斗组")

-- 批量操作
timer.StopGroup("战斗组")  -- 暂停战斗组所有定时器
timer.ResumeGroup("战斗组") -- 恢复战斗组所有定时器
```

## 定时器控制

```lua
local timerObj = timer.CreateBlock(function()
    while true do
        print("每帧执行")
        wait.frame(1)
    end
end)

-- 控制方法
timerObj:Stop()     -- 暂停定时器
timerObj:Resume()   -- 恢复定时器  
timerObj:Restart()  -- 重启定时器
print("是否活跃:", timerObj:IsActive())
print("进度:", timerObj:GetProgress())
```

## 完整使用示例

```lua
local skillTimers = {}

function castSpell(spellName, cooldown)
    if skillTimers[spellName] and skillTimers[spellName]:IsActive() then
        print(spellName .. " 技能冷却中")
        return false
    end
    
    skillTimers[spellName] = timer.CreateBlock(function()
        print("释放 " .. spellName)
        wait(cooldown)
        print(spellName .. " 冷却完毕")
    end, spellName .. "冷却", "技能组")
    
    return true
end

-- 使用示例
castSpell("吃大药", 5)  -- 5秒冷却
castSpell("吃小药", 3)  -- 3秒冷却
```
