# GUI库（GUIManager）

也许玩家需要在游戏里点点什么按钮，或者点击图片跳转到对应链接？<br>
又或者说你不在乎玩家能点什么，只是想展示一些东西？<br>

这些都可以用gui库来完成。

---

## 创建可点击的按钮

### 创建按钮

本库提供了四种按钮：

- 矩形按钮：`gui.add_button_rect(x, y, width, height, text, callback, opts)`
```lua
local myButton = gui.add_button_rect(100, 100, 120, 40, "点击我",
    function(btn)
        print("按钮被点击了!")
    end,
    {font = love.graphics.newFont(14)} -- 可选参数
)
```

- 圆角矩形按钮：`gui.add_button_roundrect(x, y, width, height, radius, text, callback, opts)`
```lua
local roundButton = gui.add_button_roundrect(250, 100, 120, 40, 10, "圆角",
    function() print("圆角按钮触发") end
)
```

- 椭圆按钮：`gui.add_button_ellipse(x, y, width, height, text, callback, opts)`
```lua
local ellipseButton = gui.add_button_ellipse(400, 100, 100, 50, "椭圆",
    function() print("椭圆按钮触发") end
)
```

- 图片按钮：`gui.add_button_image(x, y, image, callback, opts)`
```lua
local imgButton = gui.add_button_image(550, 100, "icon.png",
    function() print("图片按钮触发") end
)
```

### 修改创建参数

也许你可能不喜欢按钮中自带的字体，可能很糊，可能很小，可能颜色不是你想要的，你想要渐变色，没关系，这些都可以被修改，重点就在于最后的参数 `opts`。

下面是一些 `opts` 可以做到的功能：

- `font`：字体，大小，或者使用什么字体。
```lua
local myFont = love.graphics.newFont(18) -- 创建一个18号字体
local button = gui.add_button_rect(100, 100, 150, 40, "大号按钮",
    function() print("点击") end,
    {
        font = myFont -- 使用自定义字体
    }
)
```

- `draw`：自定义按钮绘制
```lua
local button = gui.add_button_rect(100, 200, 150, 40, "自定义渐变色",
    function() print("点击") end,
    {
        font = love.graphics.newFont(14),
        draw = function(b)
            -- 保存当前颜色
            local r, g, b, a = love.graphics.getColor()
            -- 绘制一个渐变背景（水平从左到右）
            for i = 0, b.width do
                local ratio = i / b.width
                love.graphics.setColor(0.2, 0.2, 0.8, 1 * ratio) -- 蓝色渐变
                love.graphics.line(b.x + i, b.y, b.x + i, b.y + b.height)
            end
            -- 恢复颜色并绘制文本
            love.graphics.setColor(1, 1, 1, 1) -- 白色文本
            love.graphics.setFont(b.font)
            love.graphics.printf(b.text, b.x, b.y + 10, b.width, "center")
            -- 还原原始颜色
            love.graphics.setColor(r, g, b, a)
        end
    }
)
```

- `colors`：颜色集合，可以改变正常、悬停、按下、禁用、文本的颜色。
```lua
local button = gui.add_button_rect(100, 250, 150, 40, "彩色按钮",
    function() print("点击") end,
    {
        font = love.graphics.newFont(14),
        colors = {
            normal = {0.1, 0.7, 0.3},   -- 绿色
            hover = {0.2, 0.8, 0.4},    -- 亮绿色
            pressed = {0.0, 0.6, 0.2},  -- 深绿色
            disabled = {0.5, 0.5, 0.5}, -- 灰色
            font = {1, 1, 1}            -- 白色文字
        }
    }
)
```

- `enabled`：设置按钮的初始启用或禁用状态。
```lua
local button = gui.add_button_rect(100, 300, 150, 40, "禁用按钮",
    function() print("这个回调不会触发") end,
    {
        enabled = false -- 初始即为禁用状态
    }
)
```

## 创建滑块

使用 `gui.add_slider(x, y, width, height, min, max, value, callback, step, orientation, opts)`。
```lua
local volumeSlider = gui.add_slider(100, 180, 200, 20, 0, 100, 50,
    function(value)
        setVolume(value / 100) -- 假设这是你的音量设置函数
    end,
    1, -- 步进值，每次拖动调整1个单位
    "horizontal",
    {show_value = true} -- 可选：在滑块旁显示当前数值
)
```

## 创建文本输入框

使用 `gui.add_text_input(x, y, width, height, placeholder, callback, opts)` 来创建一个文本输入框。
```lua
local nameInput = gui.add_text_input(100, 230, 200, 30, "请输入玩家名",
    function(text, isReturnPressed)
        if isReturnPressed then
            print("玩家确认名称: " .. text)
        else
            -- 实时处理输入，例如验证
        end
    end,
    {font = love.graphics.newFont(12)}
)
```

## 创建可视化表格面板

使用 `gui.add_table(x, y, w, h, headers, config)` 来创建一个可视化图表。
```lua
local scoreTable = gui.add_table(400, 180, 300, 200,
    {"排名", "玩家", "得分"}, -- 表头
    {colors = {header_bg = {0.2, 0.4, 0.7}}} -- 可选配置
)
-- 添加数据行
scoreTable:add_row({1, "PlayerOne", 1500})
scoreTable:add_row({2, "PlayerTwo", 1200})
```

## 创建窗口

使用 `gui.add_window(x, y, w, h, title, opts)` 创建一个内部窗口。
```lua
local settingsWindow = gui.add_window(200, 150, 350, 250, "设置面板", {
    closable = true,
    minimizable = true,
    maximizable = true,
    onclose = function(win) print("窗口关闭") end
})
-- 可以向窗口内添加子控件（相对窗口客户区坐标）
local innerButton = settingsWindow:add_child(
    gui._create_button{x=20, y=30, width=100, height=30, text="内部按钮"}
)
```

---

## 创建下拉菜单

使用 `gui.add_menu(x, y, w, h, items, functions)` 来新建一个下拉菜单。
```lua
local fileMenu = gui.add_menu(50, 50, 80, 25,
    {"新建", "打开", "保存", "退出"}, -- 菜单项
    { -- 对应的回调函数
        function() print("新建文件") end,
        function() print("打开文件") end,
        function() print("保存文件") end,
        function() love.event.quit() end
    }
)
```
