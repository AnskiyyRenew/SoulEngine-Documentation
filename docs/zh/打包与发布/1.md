# 打包与发布

在制作完游戏后，下一步就是要让别人玩。

接下来，就是制作完成之后的打包和发布过程。

---

## 最后设置

将 `conf.lua` 中的 `_RELEASED` 变量设置成 `true` ，也就是告诉游戏这个已经是发布版本了，游戏会自动隐藏命令台。

---

## 打包

LOVE2D所有的游戏文件，都要经过如下流程进行打包：

```
源文件项目 -> 压缩为.love -> 结合love.exe
```

所以，为了方便，Windows用户可以直接使用引擎中自带的一个程序 `LovePackager.exe` （图标为一个紫色的心，上面有一个箭头）。

> 请注意，不要在要打包的项目文件夹内运行此程序。否则，连续打包两次可能会导致您的游戏文件体积增大（例如变成2G），三次打包则可能使其呈指数型增长，达到几十GB的规模。

说人话就是剪切出来，去文件夹外面运行打包这个游戏。

---

## 测试运行

在打包后，你必须点开游戏首先运行，这不是看完logo界面就可以的事情，而是你需要尽可能完整的游玩一遍，来确认确实没有报错了，再发布。

打包后的Love2D游戏，其运行环境会发生一些微小但可能关键的变化，有时这些变化足以导致你的游戏崩溃或无法正常运行。

当然，不必担心。距离我本人上次打包出现这种情况是大小写错了一个字母导致的报错。
