# 配置文件（conf.lua）

你是否有思考过——<br>
`窗口的标题是怎么被设置的？窗口的大小是怎么被设置的？报错形式是怎么设置的？......`<br>

**那么这里就是这些问题的答案所在地了，conf.lua文件配置着这些东西。**

---

## 配置文件的所在地

配置文件和 `main.lua` 的要求一致，都需要在目录的第一层。

---

## 配置文件的内容

我们先看在函数 `love.conf` 之前的内容：

```lua
-- Soul Engine Configuration File
_VERSION = "2.4.2-alpha"

-- Set to true when building the game for release
_RELEASED = false

-- The game's information
_INFO = {
    TITLE = "SOUL ENGINE",
    VERSION = "0.0.0", -- THIS IS YOUR GAME'S VERSION, the "_VERSION" upon means the engine's version.
    AUTHOR = "Clavo Sophame",
    CONTACT = "NaN",
    WEBSITE = "NaN"
}

-- This is your window size. Change these values to set your desired resolution.
LOGICAL_WIDTH, LOGICAL_HEIGHT = 640, 480

-- Set to true to make the game fill the entire screen while maintaining aspect ratio
FILL_SCREEN = true

-- Enable error handler to show custom error screen
-- If you don't know which error crashed the game. Then you need to set it to false.
USE_ERRHANDLER = false
```
下面解释这些变量的作用：

- `_VERSION`：`SoulEngine` 的版本号，在 [入门指南第一节](../1.入门部分/1.md/#_5) 中最后一部分有所描述。
- `_RELEASED`：本游戏是否为发布版本。如果要发布游戏，请在打包之前将此变量修改成 `true` 。
- `_INFO`：拥有五个变量，看变量名进行设置修改为自己的游戏项目，通常在复制了 `SoulEngine` 模板之后就进行修改。
- `LOGICAL_WIDTH, LOGICAL_HEIGHT`：这是游戏最初的窗口大小，默认是 `640, 480` ，也就是UT游戏的窗口大小。
- `FILL_SCREEN`：这个变量的作用是设置窗口是否为居中，即左右是否留出黑边，如果设置为 `false`，那么不论窗口多大，整个游戏视图都会被放在左上角。
- `USE_ERRHANDLER`：启用这个变量以使用 `SoulEngine` 的自带报错页面。若报错后出现游戏崩溃难以获取报错代码，则需要啊把这个变量设置为 `false` 。


然后是 `love.conf` 函数，这里所有的东西都在后面有注释，自行查看即可。<br>

随后，就是 `USE_ERRHANDLER` 变量所控制的区域。如果设置了此变量为 `true` ，那么之后就会使用 `SoulEngine` 自定义的报错样式。

---

## 配置文件的注意事项

与其他的库和场景文件一样，在配置文件中不加 `local` 的字段均会被认为是 **全局变量** 。<br>

换言之，上面所列举出的所有变量均为全局变量，在场景的任何位置可被修改，请自行调配好最合适的修改时机。
