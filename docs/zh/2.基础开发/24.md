# 摄像机（Camera）

在游玩过程中，摄像机不总是定死在原地的，有可能会平移、旋转、甚至缩放，这里详细介绍了所有操作。

---

## 直接设置摄像机的参数

使用 `camera:setPosition(x, y)` 来让摄像机移动到(x, y)的位置。<br>

使用 `camera:setScale(x, y)` 来让摄像机在水平和竖直方向上进行缩放。<br>

使用 `camera:setAngle(r)` 来旋转摄像机。

```lua
_CAMERA_:setPosition(320, 240)
_CAMERA_:setScale(0.5, 0.5)
_CAMERA_:setAngle(math.rad(45))
```

---

## 边界检测

Overworld中，摄像机会随着地图的变小而被限制在一个特定的区域内，在区域内，摄像机会跟随玩家移动，而在区域外，摄像机则会定死在一个地方，这样保证了切换房间的流畅性。<br>

下面提供两个限制坐标方法：<br>

1. 直接坐标设置： camera:setBounds(0, 0, 800, 600)限制摄像机在区域 (0,0) 到 (800,600) 内移动。

2. 绘制区块设置： camera:setBoundsBlock(100, 100, 400, 300)限制摄像机在左上角为 (100,100)、宽高为 400×300 的矩形区域内移动。

*注：需通过 camera.boundActive = true启用边界检测（默认关闭）。*

## 屏幕震动

当开炮的时候，或者蓝魂被甩落地的时候，屏幕会产生一个轻微的震动。<br>

使用 `camera:shake(magnitude, duration, decay)` 来设置一个摄像机的震动情况。

- `magnitude`：震动幅度（像素）。
- `duration`：震动持续时间（帧数）
- `decay`：默认为true，意思是震动幅度随着时间衰减，设置为false则保持恒定幅度震动。

```lua
camera:shake(10, 60, true)   -- 强烈震动（幅度 10px），持续 60 帧，逐渐减弱
camera:shake(5, 30, false)   -- 持续小幅震动（幅度 5px），不衰减
```
