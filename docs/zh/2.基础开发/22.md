# 缓动动画（Tween）

在现实生活中，所有物体绝对不可能只是线性变换的，其速度一定会先变大后变小，而不是保持一个匀速。<br>

Tween库实现了这个功能，可以便捷的使用缓动动画。

---

## 创建缓动补间动画

使用 `tween.CreateTween(variableSetter, type, direction, begin, final, duration, delay, destroy)` 来创建一个补间动画。<br>

- `variableSetter`：作用匿名函数。
- `type`：缓动动画函数。
- `direction`：是`in`、`out`、`inout`中的一种。
- `begin`：起始位置。
- `final`：目标位置。
- `duration`：动画时长。
- `delay（可选）`：延迟多久执行动画。
- `destroy（可选）`：播放多久后清除动画（尽管只运行了一半也可以中途清除）。 

```lua
local sprite = sprites.CreateSprite("poseur.png", 0)
tween.CreateTween(
    function (value)
        sprite.x = value
    end,
    "quad", "inout", 320, 500, 60, 10
)
```
上面代码会让贴图的 `x` 值从320开始一直变到500，持续60帧，指令发出后10帧开始执行。

## 自创补间动画逻辑

使用 `tween.CreateCustomTween(name, easingFunc)` 来创建一个自定义的补间动画。

```lua
-- 创建自定义缓动函数
tween.CreateCustomTween("myEase", function(progress)
    -- 自定义缓动逻辑
    return progress * progress * (3 - 2 * progress)  -- 平滑步进
end)

-- 使用自定义缓动
tween.CreateTween(
    function(v) someVar = v end,
    "myEase", "", 0, 100, 60
)
```

**注：为了保证自创缓动可用，并且效果正常，建议符合f(0)=0，f(1)=1，中间保持连续。**
