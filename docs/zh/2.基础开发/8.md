# 全局变量（Global）

提供了内存变量和持久化存储（文件系统）两种管理方式，支持 Lua 表（Table）的序列化与反序列化，适用于游戏开发中的数据共享与存档管理。

---

## 基础全局变量

- `SetVariable(name, value)`: 设置变量（仅内存）。
- `GetVariable(name)`: 获取变量值。
- `EnsureVariable(name, value)`: 确保变量存在，若不存在则初始化。

```lua
-- 设置变量
global:SetVariable("playerName", "Alice")

-- 获取变量
local name = global:GetVariable("playerName")
print(name) -- 输出: Alice

-- 确保变量存在，如果不存在那么直接返回第二个参数0
local score = global:EnsureVariable("score", 0)
```

## 存储内存变量

这些变量自从被放到save/目录下，除非进行人工删除或代码删除，否则不会自己丢失。

- SetSaveVariable(name, value): 将变量保存到文件系统（save/目录）。
- GetSaveVariable(name): 从文件系统读取变量。
- EnsureSaveVariable(name, value): 确保存档变量存在。
- DeleteSaveVariable(name): 删除指定的存档文件。

```lua
-- 保存游戏设置
local settings = { volume = 0.8, fullscreen = true }
globals:SetSaveVariable("settings", settings)

-- 读取存档
local loadedSettings = globals:GetSaveVariable("settings")
if loadedSettings then
    print("Volume:", loadedSettings.volume)
end

-- 删除存档
globals:DeleteSaveVariable("settings")
```
