## 详解main.lua

`main.lua` 的代码虽然看起来多，但是实际上是可以被分块解释的。<br>
首先在开头：

```lua
if (not _RELEASED) then
    if (love.system.getOS() == "Windows") then
        local handle = io.popen("chcp 65001", "r")
        handle:close()
    end
end
```
这段代码的作用是以 `UTF-8` 模式打开终端，让print的内容能正常显示中文。<br>
可以尝试去掉这部分代码，你会看到所有的中文都变成了乱码。
<br><br>

接下来是其中的大量 `require` 的库。<br>
看到这些库很头疼吗？没关系，这只是需要的底层内容罢了。

接下来是画布：
```lua
-- Canvases
CANVAS = love.graphics.newCanvas(
    love.graphics.getWidth(),
    love.graphics.getHeight(),
    nil,
    {
        format = "stencil",
        readable = true
    }
)
CANVAS:setFilter("nearest", "nearest")      -- 取消掉抗锯齿
INTERMEDIATE_CANVAS = love.graphics.newCanvas(
    love.graphics.getWidth(),
    love.graphics.getHeight(),
    nil,
    {
        format = "stencil",
        readable = true
    }
)
INTERMEDIATE_CANVAS:setFilter("nearest", "nearest")
```
这样理解， **你所有能在窗口内看见的内容，包括里面的图片，里面的文本，全都是画布的作用——它是一个巨大的“容器”** 。<br>
而我们为了使用 `Shaders` ，会用到两个画布同时作用。<br>
**所以就这样有了CANVAS和INTERMEDIATE_CANVAS.**<br><br>

随后是一些全局变量的设置：
```lua
-- Global variables
global:SetVariable("FPS", 60)                   -- 游戏的帧率（锁帧）

global:SetVariable("LAYER", 30)                 -- 设置一个名叫LAYER的变量，数字为30
global:SetVariable("EncounterNobody", false)    -- 用于Overworld是否应该进入“但是谁也没有来”的战斗
local reset_room = "scene_logo"                 -- 玩家按下F2后会立刻传送到的房间

-- 初始化摄像机的部分，可以用于缩放，旋转一整个屏幕所看到的东西。
local Camera = require("Scripts.Libraries.Utils.Camera")
_CAMERA_ = Camera:new(0, 0, 1, 1, 0)

-- 这里是用于计算全屏大小并保留黑边居中的地方（没想到吧，全屏模式其实是硬算出来的）。
screen_w, screen_h = love.graphics.getDimensions()
scale = math.min(screen_w / CANVAS:getWidth(), screen_h / CANVAS:getHeight())
draw_x = math.floor((screen_w - CANVAS:getWidth() * scale) * 0.5 + 0.5)
draw_y = math.floor((screen_h - CANVAS:getHeight() * scale) * 0.5 + 0.5)

-- 控制帧率的必要初始变量。
local frameTime = 1 / global:GetVariable("FPS")
local startTime
```
