# 超步（SuperStep）

你应该曾见过一些丝滑的弹幕，它们并不是直直地从一个地方移动到另一个地方，而是可能在这期间，弹幕还会回旋回来，或者变色，或者做一些更复杂的动作，这些都由超步事件完成。<br>

**严格来讲，本页面算方法推荐，而不是必须这么做。**

---

## 更直观的解释

对于超步，其最基础的含义就是一个物体的 `logic` 回调函数。

```lua
local spr = sprites.CreateSprite("bullet.png", 0)

-- 初始化一个时间，这个时间只属于spr本身
spr._time = 0

-- 超步事件，物体将会自行按照逻辑进行运行，以self代指自身
spr.logic = function(self)

    -- 其时间在每帧 +1
    self._time = self._time + 1

    -- 如果时间在60以内，这个图片会慢慢向右挪
    if (self._time <= 60) then
        self.x = self.x + 1
    end
end
```

由于它能随时掌控整个贴图的属性，这种写法在回合中被广泛应用。

---

## 注意事项

值得注意的是，并不是所有场景中都兼容 `logic` 的，这可能需要自己写一个支持调用 `logic` 函数的for循环，下面是一个小例子：

```lua
for i = #egtable, 1, -1 do
    local o = egtable[i]
    if (o.logic) then
        o:logic()
    end
end
```

**上面的代码会让所有被添加进egtable的物体调用自身的logic函数。**
