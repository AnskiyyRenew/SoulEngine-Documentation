## 安装制作地图的工具

本文档所使用的制作地图的工具为[Tiled](https://www.mapeditor.org/)。<br>
是一个比较方便且稳定的地图编辑器，这也是我推荐它的原因。

### 下载

进入官网后，点击图片内所圈内容 `Download on itch.io` 即可跳转到itch.io网站准备下载Tiled。<br>
![](../img/overworld/1-1.png)<br>

如果网页加载不进去，或者很难加载进去，可以选择下面这个网址（这个链接是我分享的）：

```
https://wwatg.lanzouq.com/ipNqa3iggbmh
密码:tiled
```
[点击进入](https://wwatg.lanzouq.com/ipNqa3iggbmh)<br>

**解压后双击运行.msi文件即可安装。**

### 开启

下载完毕后，打开Tiled软件，会看到一个很大的空白页面，只有几个按钮在上面，可以准备下一个专题了。
