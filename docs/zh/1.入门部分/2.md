### 1.Lua语言

LOVE2D这个引擎所使用的语言，就是`Lua`语言。<br>
这就好比你想要看懂一本英语书，你需要先学习词汇这种最基础的东西，才可以看懂。<br>

那么Lua对于LOVE2D引擎来说，也大概是这种关系。<br>

学习Lua语言最好的地方莫过于Lua的[官网](https://lua.org)，但是问题在于，如果你想要快速开发，你肯定是没有时间迅速学习全面的。<br>

鉴于此，我们决定，**以做促学，边做边学**，这是效率最高的一个方法。<br>

当然，如果你想快速学一下更为基础的知识，点击[这个Lua教程](../Lua教程速通/1.md)，它会带你速通一些最基础的知识。<br>

### 2.LOVE引擎

首先，我们要讲清楚一个`LOVE2D`的游戏项目可以是什么样子的。<br>

一个 LOVE2D 游戏项目通常很轻量，但结构要清晰。最小可运行的项目只需要一个 main.lua 文件，LOVE 启动后会执行其中的回调函数。常见要点：

- 必要文件
    - main.lua：程序入口，常见回调有 love.load、love.update(dt)、love.draw、love.keypressed 等。
    - conf.lua（可选）：用于配置窗口大小、标题、缩放等启动参数。
- 常见目录布局（示例）
```text
mygame/
├─ main.lua
├─ conf.lua
├─ src/             # 游戏逻辑模块
│  ├─ game.lua
│  └─ player.lua
├─ assets/
│  ├─ images/
│  └─ sounds/
└─ libs/            # 第三方库（如 hump、push 等）
```
- 代码组织建议
    - 把不同功能拆成模块（require "src.game"），避免把所有逻辑堆在 main.lua。
    - 用资源管理器统一加载/缓存图片和音频，避免重复加载。
    - 使用游戏状态（state）或场景管理器来切换菜单/游戏/暂停等逻辑。
- 回调与帧循环
    - love.load(): 初始化资源与状态。
    - love.update(dt): 每帧更新游戏状态，使用传入的 dt 保证与帧率无关。
    - love.draw(): 绘制当前状态（保持绘制和逻辑分离）。
- 输入与文件
    - 常用回调：love.keypressed、love.mousepressed、love.textinput。
    - love.filesystem 用于读取/保存用户数据（跨平台路径管理）。
- 打包与运行
    - 开发时直接用 love.exe 或 love 命令运行项目文件夹。
    - 发布可将项目文件打包为 .zip 并重命名为 .love，或结合平台的可执行文件封装。
- 小贴士
    - 开发初期保持结构简单，随着项目增长再重构模块化。
    - 先做可运行的最小需求（MVP），再逐步增加复杂功能。
    - 常用第三方库放在 libs/ 并通过 require 引入，便于管理和升级。

以上内容可作为入门级的工程规范，帮助把 LOVE2D 项目从零开始组织成易维护的结构。

### 3.SoulEngine引擎

上面的内容虽然说是一个LOVE2D游戏项目的最基本的介绍，但是你既然来了这里，就一定是使用`SoulEngine`进行开发的。<br><br>
这两者的项目结构不太一样，接下来我们进行解释：<br>

```txt
SoulEngine/
├─ main.lua             # 主程序文件
├─ conf.lua             # 配置文件（在发布之前记得修改这个文件中的内容）
│
├─ Localization/        # 本地化文件夹
│  ├─ en.lua            # 英文翻译数据文件
│  ├─ zh_CN.lua         # 简体中文翻译数据文件
│  └─ LOCALIZE.lua      # 本地化库的文件，其内部含有用于本地化的函数
│
├─ Maps/                # Overworld地图文件夹，包含所有Overworld的地图数据
│  ├─ images/           # 用于存储地图的图块等图片素材
│  ├─ tmx/              # 用于存储以Tiled为主的项目文件，便于打开修改
│  ├─ tsx/              # 存储一个图片是如何被分成几个瓦片的数据
│  └─ ruins_x.lua       # 一些示例的Overworld lua数据文件
│
├─ Scripts/             # 游戏逻辑模块
│  ├─ Libraries/        # 所有使用到的Lua库
│  ├─ Scenes/           # 所有的场景独立文件
│  ├─ Shaders/          # 所有的Shader文件，使用glsl语言进行编写
│  └─ Waves/            # 所有的回合文件，均使用在scene_battle.lua文件中
│
└─ Resources/           # 所有的资源内容
   ├─ Fonts/            # 字体文件夹
   ├─ Libs/             # 拓展库文件夹，包含dll等外部库
   ├─ Music/            # 音乐文件夹
   ├─ Sounds/           # 音效文件夹
   └─ Sprites/          # 贴图文件夹
```

**在认识了所有的目录之后，接下来我们就可以正式进入开发阶段了。**
