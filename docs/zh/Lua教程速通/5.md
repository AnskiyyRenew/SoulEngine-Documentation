## 第五部分：让 Lua “记住一套操作流程”（函数）

想象一下，你每天上班前都要让小秘书做三件事：<br>

- 给你泡一杯咖啡
- 告诉你今天的天气
- 提醒你今天的会议

你不需要每天早上一字一句地重复这三条指令，你可以把这些指令打包成一个“晨间流程”。以后每天早上，你只需要说一句“执行晨间流程”，小秘书就会自动完成这三件事。<br>

这个“打包好的流程”，在 Lua 里就是 函数。<br>

代码演示：

```lua
-- 1. 定义一个函数（打包一套流程）
-- 函数名是 `morningRoutine`（晨间流程）
function morningRoutine()
    print("1. 为你泡好了一杯香浓的咖啡。")
    print("2. 今天晴转多云，气温 15-25°C。")
    print("3. 上午 10:00 有一个项目会议，请准时参加。")
    print("--- 晨间简报完毕 ---")
end

-- 定义完之后，Lua 只是“记住”了这个流程，但还没有执行。

print("现在是早上 9:00")
print("要开始晨间流程吗？")

-- 2. 调用函数（执行这个打包好的流程）
-- 只需要写下函数名加上括号即可
morningRoutine()

print("好的，开始工作！")
```

### 运行结果

```
现在是早上 9:00
老板，要开始晨间流程吗？
1. 为你泡好了一杯香浓的咖啡。
2. 今天晴转多云，气温 15-25°C。
3. 上午 10:00 有一个项目会议，请准时参加。
--- 晨间简报完毕 ---
好的，开始工作！
```

## 函数的威力之一
可以输入不同信息，得到不同结果（带参数的函数）。<br>

如果泡咖啡时，你想有时加糖有时不加糖怎么办？我们可以让函数接受“参数”。

```lua
-- 定义一个“泡咖啡”的函数，它接受一个“指令”
function makeCoffee(instruction)
    print("正在为你泡咖啡..." .. instruction)
end

-- 调用函数时，传入不同的信息
makeCoffee("加糖")    -- 输出：正在为你泡咖啡...加糖
makeCoffee("加奶")    -- 输出：正在为你泡咖啡...加奶
makeCoffee("什么都不加") -- 输出：正在为你泡咖啡...什么都不加
```

## 函数的威力之二
可以给你一个结果（带返回值的函数）。<br>

让函数去做个计算，然后把结果“还”给你。

```lua
-- 定义一个计算长方形面积的函数
-- 它需要你告诉它“长”和“宽”是多少
function calculateArea(length, width)
    local area = length * width  -- 在函数内部计算面积
    return area  -- 使用 `return` 关键字把结果“返回”去
end

-- 调用函数，并“接住”它返回的结果
myRoomArea = calculateArea(5, 4)  -- 计算长5宽4的面积
print("我的房间面积是：" .. myRoomArea .. "平方米") -- 输出：我的房间面积是：20平方米

-- 也可以直接使用函数返回的结果
print("桌子的面积是：" .. calculateArea(2, 1) .. "平方米") -- 输出：桌子的面积是：2平方米
```

## 小节

- 定义函数（制造售货机）：你设定好它内部的工作流程（function...end）。
- 参数（你投币和按键选择商品）：你给机器输入信息。
- 返回值（机器吐出的商品）：机器给你一个结果。
- 调用函数（使用售货机）：你只需要下个简单指令，复杂的工作它在内部完成。
