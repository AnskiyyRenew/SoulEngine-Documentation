## 第二部分：让 Lua “做操作和计算”

光记住不行，我们得让 Lua 干活。最基本的活就是数学计算和文本拼接。<br>

代码演示：

```lua
-- 刚才记住的内容
myName = "小明"
applePrice = 5.5
bananaPrice = 3.2

-- 1. 数学计算：买2斤苹果和3斤香蕉，总共多少钱？
totalCost = applePrice * 2 + bananaPrice * 3

-- 2. 文本拼接：生成一句问候语
greeting = "你好，" .. myName .. "！"

-- 3. 把结果“说”出来（打印到屏幕上）
print("总价是：" .. totalCost .. "元")
print(greeting)
```

运行一下，你会看到：

```
总价是：21.4元
你好，小明！
```

### 讲解
- +, -, *, /就是加减乘除。
- ..是两个英文句点，用于把两段文本连接起来。
- print()是一个最重要的指令，意思是“把你括号里的内容，显示在屏幕上”。它是我们看 Lua 工作结果的“窗口”。
