# 第七章 表中的函数

---

## 第七部分：让档案袋“自己做事”（表自己的函数）

之前我们把函数比作“打包好的流程”，把表比作“档案袋”。现在我们把它们结合起来。<br>

想象一下，你有一个“员工档案袋”，里面记录了员工的信息：<br>

- 姓名：张三
- 部门：销售部
- 基本工资：5000

现在你想知道张三这个月的总工资（基本工资 + 销售提成）。按照之前的做法，你需要：<br>

- 从档案袋里拿出基本工资
- 另外找一个“计算总工资”的流程手册（外部函数）
- 把基本工资和提成信息交给这个流程来计算

这样很麻烦！有没有更聪明的方法？<br>

有的！我们可以直接把“计算工资”这个流程，也放进“员工档案袋”里。这样档案袋就“活”了，它能自己计算自己的工资！<br>

代码演示：<br>

方法一：先创建空档案袋，再往里塞流程
```lua
-- 1. 创建一个空的“员工档案袋”
employee = {}

-- 2. 往档案袋里放基本信息
employee.name = "张三"
employee.department = "销售部"
employee.baseSalary = 5000
employee.sales = 80000  -- 本月销售额
employee.commissionRate = 0.1 -- 提成比例10%

-- 3. 最重要的一步：往档案袋里塞一个“计算总工资”的流程
-- 注意语法：函数名前面有个点，用 = 赋值
employee.calculateTotalSalary = function()
    -- 在函数内部，可以直接用 employee.xxx 访问档案袋里的其他信息
    local commission = employee.sales * employee.commissionRate
    local total = employee.baseSalary + commission
    return total
end

-- 使用：让档案袋“自己计算”工资
-- 语法：档案袋名.函数名()
print(employee.name .. "的本月总工资是：" .. employee.calculateTotalSalary() .. "元")
```
方法二：创建档案袋时，直接把流程放进去（更常用）
```lua
-- 一次性创建完整的档案袋，包含信息和功能
employee = {
    name = "张三",
    department = "销售部", 
    baseSalary = 5000,
    sales = 80000,
    commissionRate = 0.1,
    
    -- 把函数也直接定义在表里！
    calculateTotalSalary = function()
        local commission = employee.sales * employee.rate
        local total = employee.baseSalary + commission
        return total
    end
}

-- 使用方式完全一样
print(employee.name .. "的本月总工资是：" .. employee.calculateTotalSalary() .. "元")
```
方法三：更专业的写法（使用 self）<br>

上面的写法有个小问题：函数内部硬编码了 employee这个名字。如果我把这个档案袋改名叫 staff，函数就报错了。<br>

更专业的写法是使用 self这个特殊的关键字：

```lua
employee = {
    name = "张三",
    baseSalary = 5000,
    sales = 80000,
    commissionRate = 0.1,
    
    -- 使用冒号语法定义，函数会自动获得一个叫 `self` 的参数
    calculateTotalSalary = function(self)
        -- `self` 代表“调用这个函数的那个档案袋本身”
        local commission = self.sales * self.commissionRate
        local total = self.baseSalary + commission
        return total
    end
}

-- 调用时也要用冒号，这样 Lua 会自动把 employee 作为 self 传进去
print(employee.name .. "的工资是：" .. employee:calculateTotalSalary() .. "元")
```

self的比喻：<br>

self就像档案袋在自言自语时说“我”这个词。<br>
当你说“档案袋，计算一下你的工资”时，档案袋内部的函数就知道“我”指的就是“档案袋自己”。<br>
这样无论档案袋叫什么名字（employee、staff、zhangsan），函数内部都用 self来指代，就不会出错。<br>

更生动的例子：游戏中的角色
```lua
-- 创建一个“游戏角色”档案袋
hero = {
    name = "勇士",
    level = 1,
    health = 100,
    attack = 15,
    
    -- 角色自己的功能：攻击敌人
    attackEnemy = function(self, enemy)
        print(self.name .. " 攻击了 " .. enemy.name .. "！")
        enemy.health = enemy.health - self.attack
        print(enemy.name .. " 剩余生命值：" .. enemy.health)
    end,
    
    -- 角色自己的功能：升级
    levelUp = function(self)
        self.level = self.level + 1
        self.attack = self.attack + 5
        self.health = self.health + 20
        print(self.name .. " 升级了！现在是 " .. self.level .. " 级！")
    end
}

-- 创建一个“怪物”档案袋
monster = {
    name = "史莱姆", 
    health = 30,
    attack = 5
}

-- 让角色自己行动
print("=== 战斗开始 ===")
hero:attackEnemy(monster)  -- 勇士攻击史莱姆
hero:levelUp()             -- 勇士升级
hero:attackEnemy(monster)  -- 勇士再次攻击史莱姆
```
运行结果：

```
=== 战斗开始 ===
勇士 攻击了 史莱姆！
史莱姆 剩余生命值：15
勇士 升级了！现在是 2 级！
勇士 攻击了 史莱姆！
史莱姆 剩余生命值：0
```
## 核心思想总结

表自己的函数 = 让档案袋具备“行为能力”<br>

普通变量：档案袋里的“静态信息”（姓名、年龄、工资...）<br>

表内函数：档案袋里的“动态能力”（计算工资、攻击敌人、升级...）<br>

这样设计的好处：<br>

- 高度组织化：相关的数据和操作都放在一起，管理起来非常清晰。
- 自成一体：档案袋变得“聪明”了，它能自己处理自己的数据。
- 代码复用：我可以创建很多个员工档案袋，每个都有自己的 calculateTotalSalary函数。

这就是面向对象编程的雏形——把数据和操作数据的方法捆绑在一起。在 Lua 中，就是通过“表包含函数”这种简单而强大的方式实现的。<br>

现在你再看 a = {b = function} ... end这样的代码，就能明白：<br>

- a是一个档案袋
- b是这个档案袋里的一个“特殊能力”
- 你可以用 a:b()来让档案袋 a执行它自己的 b能力
