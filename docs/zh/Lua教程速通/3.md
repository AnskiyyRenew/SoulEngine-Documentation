## 第三部分：让 Lua 做“判断”

生活中我们经常需要做选择，比如“如果下雨，我就带伞”。Lua 也能做判断。<br>

代码演示：

```lua
-- 记下我的钱包里有多少钱
myMoney = 50
-- 记下一杯奶茶的价格
milkTeaPrice = 20

print("我钱包里有" .. myMoney .. "元")
print("一杯奶茶" .. milkTeaPrice .. "元")

-- 如果...那么... (if...then...)
if myMoney >= milkTeaPrice then
    -- 如果条件成立（我的钱 >= 奶茶价格），就执行这里的指令
    print("太好了，我能买一杯奶茶！")
    myMoney = myMoney - milkTeaPrice -- 买完奶茶，钱要减少
    print("买完奶茶，我还剩" .. myMoney .. "元")
else
    -- 否则（如果钱不够），就执行这里的指令
    print("哎呀，钱不够，喝不起奶茶了。")
end

print("判断结束，生活继续~")
```

### 讲解

- if 条件 then是判断的开始。条件就是一个问题，比如“我的钱是否大于等于奶茶价格？”。
- 如果问题的答案是“是”（条件为真），Lua 就会执行 then和 else之间的指令。
- 如果答案是“否”（条件为假），Lua 就会跳过上面那段，去执行 else和 end之间的指令。
- end表示这个判断指令块结束了。
