## 第六部分：让 Lua “管理一组相关信息”（表 - Table）

到目前为止，我们的变量都是独立的“盒子”。但现实世界中，很多东西是成组出现的，比如：<br>

- 一个“学生”的信息：包括姓名、学号、成绩。
- 一个“购物车”里的所有商品。
- 一个星期里的所有天数。

如果为每个信息都单独创建一个变量，会很散乱。Lua 用 表（Table）​ 来解决这个问题。表是 Lua 中唯一的数据结构，它超级重要！<br>

**你可以把表理解成一个 大档案袋​ 或者 一个有很多格子的储物柜。**<br>

代码演示：

1. 表作为“档案袋”（存储带有属性描述的信息）

```lua
-- 创建一个表，用来存放“学生小明”的档案
-- 用花括号 {} 来创建一个表
studentXiaoMing = {
    name = "小明",   -- name 是“属性名”，"小明"是“值”
    studentId = 1001,
    mathScore = 90,
    englishScore = 85
}

-- 如何查看档案袋里的内容？
-- 使用“档案袋名.属性名”或者“档案袋名["属性名"]”
print("学生姓名：" .. studentXiaoMing.name) -- 方式一（更常用）
print("学号：" .. studentXiaoMing["studentId"]) -- 方式二
print("数学成绩：" .. studentXiaoMing.mathScore)

-- 也可以修改或增加信息
studentXiaoMing.mathScore = 95 -- 修改数学成绩
studentXiaoMing.class = "三年级二班" -- 增加班级信息

print("修改后，小明的数学成绩是：" .. studentXiaoMing.mathScore)
print("小明在：" .. studentXiaoMing.class)
```

2. 表作为“储物柜”（存储一系列类似的东西，比如清单）

```lua
-- 创建一个“待办事项”清单表
-- 这种表按顺序给每个格子编号（从1开始）
todoList = {"吃早餐", "写代码", "午休", "继续写代码", "睡觉"}

-- 查看储物柜里第几个格子放的是什么？
-- 使用“表名[编号]”
print("第一件事是：" .. todoList[1]) -- 输出：第一件事是：吃早餐
print("第三件事是：" .. todoList[3]) -- 输出：第三件事是：午休

-- 知道长度，就可以用循环轻松处理整个表
print("今天的待办事项：")
for i = 1, #todoList do -- #todoList 能自动获取表的长度
    print(i .. ". " .. todoList[i])
end
```
表和函数结合的超强例子：

```lua
-- 定义一个“学生”表
student = {
    name = "小红",
    scores = {85, 92, 78} -- 表里甚至可以再套一个表！（成绩列表）
}

-- 定义一个函数，计算平均分
function calculateAverage(scoreTable)
    local sum = 0
    for i = 1, #scoreTable do
        sum = sum + scoreTable[i]
    end
    return sum / #scoreTable
end

-- 把小红的成绩列表传给函数，计算平均分
avg = calculateAverage(student.scores)
print(student.name .. "的平均分是：" .. avg)
```

运行结果：

```
小红的平均分是：85
```

## 总结

现在，你的“Lua 小秘书”升级了！<br>

变量：贴了标签的单个盒子，存放零散信息。<br>

函数：打包好的标准操作流程。一次定义，多次使用，还能接收指令和返回结果。让代码整洁、高效。<br>

表：档案袋或储物柜。用来把一组相关的信息整齐地收纳在一起，是 Lua 管理复杂数据的基础。
