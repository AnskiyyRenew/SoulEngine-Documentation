再次抛开其他的东西，让我们看看敌人表拥有什么。

```lua
{
    name = localize.Enemies.Poseur.Name,
    defensetext = "MISS",
    misstext = "MISS",
    exp = 1,
    gold = 1,
    maxhp = 100,
    hp = 100,
    maxdamage = 999,

    killable = true,
    canspare = false,
    dead = false,

    actions = localize.Enemies.Poseur.Actions,
    position = {
        x = 320 - 150,
        y = 140
    }
},
```

### 敌人属性

- `name`：敌人的名称，这里用了本地化工具表示的。
- `defensetext`：当玩家挥刀出去，未造成伤害之后所弹出的句子。这里可以学习ULB改成 `NO EFFECT`.
- `misstext`：当玩家进入校准界面，但是没有挥刀，校准条出界了，导致直接MISS之后所弹出的句子。
- `exp`：这个敌人有多少exp。
- `gold`：这个敌人有多少gold。
- `maxhp`：这个敌人最大血量是多少。
- `hp`：这个敌人目前的血量有多少（在原UNDERTALE中，如果不救怪物小孩直接走开，Undyne会跳下去救，再次战斗观察可以发现Undyne少了一点血，这里就可以直接设置）。
- `maxdamage`：玩家所能造成的最大伤害，这里不用atk和def等一系列复杂的计算，而是直接写出了maxdamage，你也可以每帧都重新给予一个新的maxdamage来模拟随机伤害。
- `killable`：这个怪物血条归零之后是否会被杀（比如Napsta幽灵被清空血条之后，战斗不会立刻结束，幽灵还会继续跟你说话解释原因，然后战斗才会结束，这时候就会需要现将killable设置为false，然后再设置为true）。
- `canspare`：是否可以被饶恕，达成特定选项后可以尝试饶恕。
- `dead`：是不是死了。
- `actions`：这个敌人有什么选项可以用。
- `position`：当玩家挥刀的时候，这个目标位置是相对于哪里来说的。

### 玩家设置

- `Player`：这里可以设置玩家的名字、等级、最大hp、hp。
- `Inventory`：这里是玩家的背包，可以放无穷多个东西，会自动跟随页面自动排版（但是如果是Overworld和箱子交互最多只能带走八个物品）。

## 开头杀效果

既然现在已经知道了所有东西，那么我们试试来制作出和Sans一样的开头杀吧。<br>

首先找到 `STATE` 一栏，这里就是进入战斗后第一个状态的地方。

由于我们知道，当 `STATE` 状态为 `DEFENDING` 的时候，会立刻进入对方回合，所以，我们直接把STATE设置为DEFENDING即可做到进入场景就是开头杀的效果。

```lua
STATE = "DEFENDING"
```

## 敌人 MISS 效果

虽然我们上面知道如何设置一个MISS文本了（未造成伤害），但是我们仍旧不知道怎么将敌人设置成可以规避玩家攻击的啊。

所以，接下来我们需要设置 `maxdamage` 变量，将玩家的 `最大伤害` 设置成小于0的，这样就会以无法触发攻击而走上 MISS 的道路。

```lua
{
    name = localize.Enemies.Poseur.Name,
    defensetext = "MISS",
    misstext = "MISS",
    exp = 1,
    gold = 1,
    maxhp = 100,
    hp = 100,
    maxdamage = -999, -- 伤害变成-999

    killable = true,
    canspare = false,
    dead = false,

    actions = localize.Enemies.Poseur.Actions,
    position = {
        x = 320 - 150,
        y = 140
    }
},
```

上面代码中的敌人就会成功规避这次攻击触发MISS文本。
