# Lua报错

开发过程中，最常见的，也许就是Lua报错了（毕竟是在写Lua代码而不是其他代码）。<br>
如何在此页面迅速查找自己的报错以及对应的原因？按下 `Ctrl + F` 或在手机打开页面搜索，然后输入几个关键词，可以迅速锁定报错。

---

## 常见报错

这些报错通常都是粗心或检查不到位导致的报错。

- `attempt to call a non-function value`<br>
试图调用一个非函数类型的值，比如 local x = 123; x()。

- `attempt to index a nil value`<br>
尝试对一个 nil值进行索引，例如 local t = nil; print(t.key)。

- `attempt to perform arithmetic on a string value`<br>
尝试对字符串进行算术运算，例如 local s = "hello"; print(s + 5)。

- `unexpected symbol near '...'`<br>
语法错误，通常在代码中出现意外的符号，比如缺少括号或拼写错误。

- `'end' expected (to close 'function' at line ...)`<br>
代码块缺少 end闭合，常见于函数、if、for等结构。

- `bad argument #1 to '...' (expected ..., got ...)`<br>
函数参数类型错误，比如传递给 string.len()的参数不是字符串。

- `cannot use '...' outside a vararg function`<br>
在非可变参数函数外部错误使用了 ...语法。

- `'then' expected near '...'`<br>
if语句缺少 then关键字，例如 if x > 5 print(x)。

- `attempt to compare number with string`<br>
尝试比较数字和字符串，例如 if 5 == "5" then。

- `attempt to concatenate a nil value`<br>
尝试拼接 nil值，例如 local x = nil; print("value: " .. x)。

- `syntax error near '...'`<br>
语法错误，通常是由于拼写错误、缺少符号或错误的结构导致。

- `cannot call method '...': a nil value`<br>
尝试调用一个对象上不存在的方法，例如 local obj = {}; obj:undefinedMethod()。

## 阈值报错

> 观前提醒：LOVE2D的lua环境真的很宽松，阈值报错在这里都是非常少见的。但是以防万一你遇到了阈值错误，这里还是给出所有原因。<br>
对于阈值错误，解决方法就是把所有有关内容放到一个表里变成一个变量。
```lua
-- 十个变量
local time1, time2, time3, ......

-- 对lua来说，只有time这一个变量
local time = {t1 = 0, t2 = 0, t3 = 0, ......}
```

全局环境、一个文件、甚至一个函数都不能有过多的变量，接下来是阈值类报错列举：

- `too many upvalues in function`<br>
函数捕获的外部局部变量数量超过 Lua 的上限。

- `too many local variables in function`<br>
单个函数内定义的局部变量数量超过限制。

- `too many constants in function`<br>
函数中使用的常量数量超过 Lua 的常量表大小限制。

- `control structure too long`<br>
例如 if...elseif链条过长，或 case语句过多。

- `function or expression too complex`<br>
代码块嵌套过深或表达式过于复杂。

- `too many syntax levels`<br>
语法嵌套层级过深，比如多层循环或条件语句。

- `table overflow`<br>
初始化表时元素数量超过限制，例如 local t = {1,2,3,...}元素过多。

- `string length overflow`<br>
字符串字面量长度超过 Lua 允许的最大值。

- `parser stack overflow`<br>
解析代码时语法结构导致内部栈溢出。

- `too many vararg functions`<br>
脚本中可变参数函数过多。

- `too many captures in pattern`<br>
正则表达式模式中捕获组数量超过限制。
