# 翻译与本地化

---

在 `SoulEngine` 的根目录中，可以看到一个 `Localization` 文件夹，这里面放着两个语言的翻译文件和一个翻译库。

## 创建一个自己语言的翻译文件

请参照（或‘复制’）其他已完成的文件的变量，这些变量是可靠的，然后边打开游戏边进行游玩、测试翻译效果。

```lua
-- 中文版本：
return {
    EncounterText = "*[pattern:chinese] 你什么都没遭遇到！",
    Enemies = {
        Poseur = {
            Name = "[preset=chinese]颇似儿",
            Actions = {
                "[preset=chd]查看", "[preset=chd]欣赏"
            }
        },
        TheOther = {
            Name = "[preset=chinese]敌人名称",
            Actions = {
                "[preset=chd]查看", "[preset=chd]欣赏"
            }
        },
    },
}

-- 英文版本：
return {
    EncounterText = "* You encountered nothing!",
    Enemies = {
        Poseur = {
            Name = "Poseur",
            Actions = {
                "Check", "Appreciate"
            }
        },
        TheOther = {
            Name = "EnemyName",
            Actions = {
                "Check", "Appreciate"
            }
        },
    },
}
```
综上所述，所有的变量都是错不了的。

## 制作者需要会的

上面只是一些翻译人员的工作，而下面，是身为游戏制作者的你，需要做好的底层：

使用 `localizetext(language, element, args)` 来制作一个本地化文本，就如我们上面所粘贴的部分例子来说。

```lua
localizetext("en", {"Enemies", "TheOther", "Name"})
```
这样我们可以获取一个敌人名字。

### 格式化

有些时候，玩家的名字你是无法确定的，就比如死亡界面的文本：

```lua
GameoverText = {
    "[voice:v_fluffybuns.wav][speed:0.5]* %s!\n* [pattern:chinese]保持你的决心.",
}
```

如果无法确认名字，这时候就需要一个占位符来填充玩家名字，在使用的时候，则需要：

```lua
localizetext("en", "GameoverText", {Player.name})
```

这样，玩家的名字就被填充进了 `%s` 的位置。
